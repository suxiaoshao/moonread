# 阅读统计：回看与历史位置

本地计时、章节覆盖、统计页面及自动同步实现规则见[统计设计](../design/statistics.md)和[数据同步](../data/sync.md)。本计划仅保留尚未完成的分析能力；真实云端及长时验证集中在[验证记录](../engineering/verification.md#待完成的验证)。

## 回看次数与正文分布

在已有 UTF-8 范围、连续访问与3秒有效覆盖基础上计算有效再次访问和正文分布，不将边界微调、重复回调、布局重排或数据库15秒检查点计成新回访。部分交叠按实际范围计，断开跳转不拼接；覆盖字数与 UTF-8 坐标分开。目录修正只改范围归属，不清掉事实。缺失历史不能伪造回填。

依赖现有稳定事实 ID、正文 SHA 和查询接口；先确定派生查询及图表，再接界面。完成条件：跳章不虚报、离开后有效回看增加次数、局部交叠不把整屏算再读一遍，渐进完成/目录修正后可重算，事件量有界且不逐字逐帧写库。统计规模查询性能见[性能待优化](../engineering/performance.md#待优化)。

## 历史位置回访

从时间/书籍明细跳到当时正文，复用临时查阅与原正式位置保护。检查原件不可用、准备中、目录修正和跨窗口；回到正式阅读不误写历史位置，不把查看统计算正文阅读。

## 已确定边界

各设备独立事实如实累加，即使时间重叠也不扣除；同一事实重复到达不得重复入账。旧计划的跨设备时间重叠去重已被此规则取代。清理不动 TXT、批注、书签、续读或元信息；正式阅读与查阅都参与统计，仅正式阅读更新最近和续读。暂停/清理后的旧写入不得复活数据。

单书暂停统计仍是候选，不借此引入单书设置继承。目标、打卡、速度、外部统计导入/导出均非当前完成条件；自然日已确定，不加凌晨跨日设置；预计读完时间明确不做。朗读尚未实现，不预留朗读计时器。每阶段只做受影响构建/回归，设备及长期测量按当轮授权。
