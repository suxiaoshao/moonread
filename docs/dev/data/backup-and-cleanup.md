# 阅读数据管理、备份与缓存

本文是已发布行为的格式与操作契约；同步裁决和整书删除传播只在[同步设计](sync.md#整书阅读数据删除与备份恢复)定义。


设置「数据管理」从新用户表的正式正文 SHA 与当前状态列书，包含暂无本机小说的记录；pending 身份另提示。列表可搜索、排序和选择删除，导出始终是「导出全部」，不受筛选或多选影响。书架内小说详情的清除入口调用同一服务；从阅读器进入的详情不显示该按钮。配色不属于整书删除范围。

数据管理总览不预读完整阅读记录；进入「查看与删除」或「需要处理」时才做盘点。设置首页的「存储空间」按本机可读取的文件长度统计，分类显示正文与封面、阅读数据库、导入与临时文件、旧版数据、App 本体和其他。App 本体与其他构成仅供查看。扫描从 App 本体、系统提供的 Library、Documents、临时目录和已授权的 App Group 开始，避开容器根的系统私有项。扫描不跟随外部书架或符号链接，文件按身份只计一次。

设置首页的「存储空间」行与存储总览使用同一占用统计。首次盘点保留总览和分类结构，尚未读到的数字用占位显示。清理进度在原按钮处显示，列表保留，右上角可以取消。正常结束和取消都在重新盘点后显示实际清理结果；已清空的过时导入文件从可清项目中移除。

「导出备份」立即启动全量导出，与小说信息导出共用状态行和后台执行生命周期。收起进度页后可从备份区查看同一任务或结果。主动停止在本次工作结束后回到初始态。失败或后台到期保留结果，可重试或关闭。生成的结果保留到点「完成」或成功分享，取消系统分享回到结果。退出进程后重新发起。

「导入备份」从选中文件起进入同一任务页，检查、预览、执行和结果可以收起后从备份区重开。检查只读，由各类数据的合并规则判断相同、保留本机或需恢复；按正式正文 SHA 汇总逐书差异，全局记录单列。预览先列在书架上的书，再列未在书架的书，两组各自按名称自然排序。没有待恢复内容就直接完成；有差异才确认，由原事务针对数据库现状合并整包。停查会取消文件协调，并在解包／摘要和库内遍历中响应。写入提交前停止会回滚，提交后显示完成。失败保留原因，仍有效的暂存可供重试，账户变更后需重新预览。任务仅在本进程有效。

若提示「上次删除仍在同步，请稍后再导入」，此次导入未写入任何改动，暂存文件可直接重试。相关删除已确认且本机完成下一次成功拉取后，重试会用同一个文件重新检查和预览。同步判定见[阅读数据同步](sync.md)。

阅读数据列表展示上次来源线索、最后阅读时间和可确认的全文进度；同名记录用序号区分，不按标题合并身份。未知全文长度只提示有进度/统计，不猜百分比。“需要处理”只查任务和授权元数据：已完成任务进页重试一次晋升，未完成任务可继续原 bookId，失效外部书架可直接重新授权；缺失来源不按文件名自动重绑。用户可确认丢弃指定的原始 pending 键，保留对应正式 SHA 的数据和小说原件；看不懂的记录仅说明原因。批量删除从「查看与删除」发起，全选作用于当前筛选和搜索结果，确认仍受盘点时的账户配置约束。确认后使用与导入和导出相同的后台执行机制。进度页可以收起，并从「查看与删除」或数据管理的「阅读数据」分区再次打开。成功和失败保留到用户处理结果，失败可重试。删除在提交前响应系统中断，提交后仍显示实际结果。

`.moonread-backup` v1 是 ZIP，manifest 固定 `scope=all`、`identityVersion=normalization-v1`。五个 JSONL 成员保存原始位置 token、资料/人工目录（包括 excluded/null）、完整批注候选、事实与统计清除载荷；封面以不可变 ID 和原字节附带。配色随全部导出；小说、AI、凭据、书架授权和偏好不导出。缺附件、pending 或未知必需载荷不能生成声称完整的备份。未知可选传输扩展只留在暂存，不作用于用户事实。

当前新用户库导出 v2，并继续读取 v1。正式候选（包括撤回和批注因果）、这些候选引用的封面原字节，以及事实／连续段／清除从同一个库的读事务取得；已结算的 current/day、设备偏好和书架描述不作为备份权威。非历史隔离记录没有通用可逆的归档成员，缺失附件或无法完整表示的记录会阻止完整备份，不会静默丢弃。

Rust 负责 ZIP/路径/摘要安全，Swift 复用 UserSyncJSON 与用户事实接入。拒绝越界、链接、重复/大小写碰撞、未列成员、截断及摘要不符；压缩包上限 512 MiB、解包 2 GiB、成员 100000、单记录 16 MiB、资产 32 MiB。流式解包和记录读取；用户库原子恢复另限成员合计 128 MiB，超限提示无法一次处理，不称为损坏或部分成功。预览只读，账户/configuration 变化后拒绝旧预览；确认时在事务里重新校验并合并，不以进程级 projectionVersion 拒绝；位置压缩不另行保存，只在最后提交一次，保留原时钟、因果和 ID，重复导入不累计统计，旧备份不会强制覆盖较新位置。

存储空间按类别查看，右上角「清理」可跨类勾选可清项目。「阅读与封面缓存」涵盖本机正文缓存，盘点与清理均直接使用索引，再次阅读需要可访问的原文件。若命中打开的阅读请求，确认中列出书名，沿用保存进度与退出阅读的流程；保存失败或正文仍被其他工作持有时跳过。未结束的导入、待续做或晋升任务继续保留正文。缓存清理保留文件索引、来源身份、手选编码、原件与阅读数据；索引库内可复用的空间可能还计入文件大小。封面缓存清理涵盖缩略图、可从库内附件还原的读出副本，以及各本机库均无对应附件的遗留读出副本。清理跳过正在加载的文件。附件回收事务提交后尝试移除对应的读出副本，失败时可从存储空间再次清理。

小说信息解包目录、检查库和预览草稿随任务阶段的所有者释放。强退留下的暂存由新进程创建暂存前回收，也可从存储空间清理。续做原包另存，仍关联任务时保留并计入占用；无主目录须核对当前环境和另一环境的索引。旧索引须有实际迁入版本和已启用的新索引作为证明；旧用户库及未接管的旧目录仅统计。ShareInbox 用户输入、在用工作副本及真实书架文件继续由原所有者处理。

整理阅读数据库是单独的手动操作。同步或其他导入、导出在途时等待其结束后再操作。整理期间保留盘点内容，在操作按钮原位显示进度，并提示开始后无法取消。当前用户库所有者排空读者、复核库 lease，按引用回收孤儿封面，以 `VACUUM usr` 归还该库空闲空间。保留其他用户库、正文索引和同步状态。结果分别显示清除的封面和实测文件大小差。

资料编辑和小说信息导入复用同字节附件；同一本书的有效封面未变时不再写候选。替换、移除、清空和恢复后，在已有回收条件下只回收失去最后一个候选引用的附件。备份恢复沿用包内附件身份，按候选合并后的引用写入附件，仍可补齐保留候选缺失的同 ID 字节。备份的多余附件条目通过校验后跳过。

导出和删除先等待 StatisticsWriter 的当前写入结束（drain）；统计每批只写一次，失败批次丢弃并提示错误，不影响之后的导出或删除。导出随后取得 userDataOperation 检查 pending 并完成同池读快照；不在持有该操作时等待统计写入，避免相互等待。删除只在 drain 后检查仍然开着的阅读器，没有统计 discard 或重试批次。App 启动及新导出前回收旧 export-* / import-*，保护进行中的解包／导出、当前预览暂存和当前备份；系统分享复用 LibraryExport 的独立副本及完成回调，不让目录回收影响活跃分享。导入成功复用现有 received-data 通知刷新主题 snapshot，并发出 `bookMetadataChanged`，与 CloudKit 导入和普通资料保存共用书籍资料刷新入口。封面资产的实际摘要必须同时匹配 manifest 和 assets/<sha>.bin 文件名。
