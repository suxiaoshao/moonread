# 产品方向

月读是免费、无广告、MIT 开源的本地 TXT 小说阅读器，优先满足个人 iOS/iPadOS 阅读需求。没有书城、书源或内容分发服务；用户管理自己的小说。核心交付标准是舒服、连续阅读，正文空间、稳定位置、翻页/选字和按需操作比功能清单重要。

## 已采用的边界

- 书架统一为真实文件夹树。内置“我的书架”固定管理本地与自身 iCloud Documents 根，不让用户选根、移动根或移除入口；内部文件支持明确的改名、移动、建目录和删除。外部书架使用系统授权。
- 小说原件与正文 SHA 下的阅读事实分离；同正文多来源共享记录，正文变化保留旧记录。iCloud Documents 负责云文件，CloudKit 私有库负责阅读事实及配色方案；排版、当前配色选择等设备偏好留本机。详细边界见[数据](data/README.md)与[同步](data/sync.md)。
- 阅读支持滚动/分页、卷章识别与修正、搜索、书签和私人批注。单书搜索是字面量/单行 Rust 正则，不承诺完整 ripgrep 语法。默认文字封面可由用户图片替换，配色与纹理不改变正文或保存坐标。
- 分享 TXT、导入/导出原件、索引、标签浏览、阅读统计与阅读数据备份服务于用户自己的书库。备份不是小说分发包；清缓存与删除用户事实是不同操作。
- AI 是默认关闭的可选助手，用户使用自己的 Key 或受支持登录；基础阅读不依赖 AI。主动发送受共享许可约束，修改资料/文件需用户确认；中国大陆店面不提供 AI。细则见[AI 设计](design/ai.md)。
- 可选消耗型打赏不解锁内容或功能，不催促、不建支持者等级，付款走 Apple。详见[支持月读](design/tip-jar.md)。

## 设计与演进

优先使用原生导航、菜单、选择、排版与可访问性；统一主题角色，状态/主要操作按任务呈现。按规则语义、数据权威和平台依赖选择唯一 owner，不以迁到某种语言为目标。发布后原件和持久化兼容是硬边界。

这里维护产品取舍，不维护功能进度；已实现规则在各专题，1.3 已定待实现与其他候选见[后续安排](roadmap.md)，实际验收见[验证原则与证据](engineering/verification.md)。
