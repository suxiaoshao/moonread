# 阅读统计设计

状态：2026-10-05，本地计时、统计 Tab、统一单书详情及章节覆盖已实现；首页改为所选范围摘要、日节奏图与书目，精确时段移入日期详情。回看分析及统计自动同步已接入但真实云端未验收，见[后续实施计划](../plans/statistics.md)。参考证据见[两款阅读器对照](../research/readers.md#阅读统计对照)。

单书统计已并入[小说详情](book-details.md)，入口按来源定位到信息或阅读区域，并继承期间；章节目录显示累计阅读覆盖。本文维护统计指标与采集口径，不另设独立单书统计目的地。

## 已明确的方向

- 页面优先回答“最近读了多少、读了哪些书、哪些天在读”，回看时回答“某月/某年读了什么”。所选范围的总时长、阅读日数和书数在最上方；日节奏图只显示每天读了多久，不设目标线、连续天数或评分；精确时段按需在日期详情查看。
- 阅读书目支持按最近阅读时间和阅读时长排序。
- 独立“统计”Tab，与书架、设置并列。
- 临时查阅正文满足相同停留规则时计入统计，不改变正式续读位置和最近阅读排序。
- 目录、设置、搜索列表和批注编辑暂停正文计时；正文选字仍计时。
- 章节使用“估算覆盖率”“回看次数”，快速划过不算读完，也不宣称完整读了几遍。
- 日期按阅读发生地的自然日、午夜分界；月历周起始跟随系统，不增加凌晨跨日设置。
- 记录什么时候看了什么，并考虑章节覆盖率、哪些位置反复读过。
- 锁屏、熄屏不能计时；静止看文字与长时间闲置需要区别。
- 无正文交互的闲置计时上限确定为 2 分钟（120 秒）；达到后暂停，再次操作正文恢复，不补算闲置。
- 不提供预计读完时间，包括剩余阅读耗时和预计读完日期。当前没有朗读功能，统计方案只处理看正文，不规划朗读统计。
- 按规范化正文 SHA 关联数据，沿用文件与阅读数据分离的约定。改名、移动或从另一书架打开同一正文不产生重复书籍统计。

应用使用“书架／对话／统计”三个原生 Tab 及独立搜索入口；设置从书架首页齿轮进入。设置首页的“阅读统计设置”与统计 Tab 菜单中的“统计设置”进入同一个记录开关、计时说明和“清除阅读统计”页；统计查看仍在统计 Tab。

## 页面层级与首页

```text
统计
├── 时间范围：近 7 天 / 月 / 年 / 全部
├── 所选范围摘要：总时长 · 阅读日数 · 读过的书数
├── 节奏图：近 7 天每日柱 / 月历 / 年内各月柱 / 全部的各年柱
│   └── 点按有阅读的某天 → 日期详情：当天钟点时段图与各次阅读
└── 读过的书：最近阅读 / 阅读时长，前 5 本＋查看全部
    └── 单书详情
        ├── 小说信息、我的阅读（状态、位置、当前章估算覆盖）
        ├── 累计时长 / 阅读日数 / 首次与最近阅读
        └── 时间范围（同上语义）→ 期间时长与阅读日、节奏图、可展开的阅读时段
```

首页按一个纵向页面排布，不给每个数字单独铺大卡片，不在每个数字旁加图标，不放常驻秒表或完整操作日志。

| 顺序 | 内容与默认表现 | 点击后 |
| --- | --- | --- |
| 时间范围 | 默认“近 7 天”：截至今天的 7 个当地自然日，包含今天。“月”“年”是日历自然月/年，只有它们有前后切换；范围行始终写明日期，例如“9月29日 – 10月5日”“2026年10月”“2026年”，当年日期省略年份 | 下方摘要、节奏图和书目共用这个范围 |
| 范围摘要 | 总时长（大字）与“N 个阅读日 · M 本书”；书数为范围内有阅读记录的不同正文，不是读完本数 | 固定信息，不作为按钮 |
| 节奏图 | 近 7 天为 7 根每日柱，无阅读的日子保留为零，最右一天标为“今天”；月为按系统周起始对齐的月历，深浅表示当天时长，尚未到来的日子只描边；年为已开始的各月柱，之后的月份不画成零；全部在超过一年时显示各年柱，否则省略 | 点按有阅读的某天打开日期详情；VoiceOver 逐项读出日期与准确时长 |
| 读过的书 | 默认最近阅读，前 5 本＋查看全部；右上菜单切换按时长，保留所选排序 | 单书详情；完整列表支持书名搜索 |

“今天”指当地自然日，不是最近 24 小时；日期记录口径见下文，与选择哪个显示范围无关。不再提供单独的“日”分段、自然周或固定的今日/本周摘要。

### 书目列表与排序

- 每行包含 30×42pt 小封面、单行书名、细横条与紧随其后的期间阅读时长、最近阅读时间。横条按范围内时长最长的书缩放、没有底色轨道，只用于比较时长，不表示阅读进度。不再提供书籍时长占比圆环：它与横条重复同一组数据。
- “最近阅读”按所选范围内最后一次正式阅读时间倒序；范围内只有查阅的书仍在列表中，以“仅查阅”标识置于有正式阅读的书之后、按书名稳定排列，不用查阅时间刷新正式排序。“阅读时长”按该范围内正式阅读与查阅的合计时长倒序，同值按最近正式阅读时间、稳定正文身份排序。选择全部时间才按累计时长。
- 一书一行，按正文 SHA 去重；这里不是把每次开书列成一行。书架首页的最近阅读继续按时间排序，不受统计页排序影响。
- 统计中的历史不会因为“从书架最近阅读移除”而删除。删除统计记录也不重置续读位置、书签或笔记。
- 点击行进入统计详情；继续阅读由明确动作触发，不混淆“查看统计”与“开书”。

### 指标定义

| 指标 | 口径 |
| --- | --- |
| 阅读时长 | 合格的前台正文停留时间，含正式阅读、临时查阅与回读，扣除暂停/闲置；为估算值 |
| 期间读过书籍数 | 范围内有有效正文阅读片段的不同正文数，包含查阅并按 SHA 去重；不是完成本数或导入数量 |
| 阅读天数 | 范围内有有效正文阅读时长的日期数，包含查阅；小于一分钟也不能先舍入为零再判断 |
| 最近阅读 | 最近一次有效正式阅读时间；扫描目录、导入、下载和查阅不刷新 |
| 本次阅读起止 | 从本次首次正文阅读到末次有效片段结束；期间可能有暂停，起止之差不等于阅读时长 |
| 阅读覆盖率 | 有效阅读范围去重后占该章/书正文的比例；估算且不等于续读位置 |
| 回看次数 | 某部分离开后再次访问并达到有效停留条件的次数；首次访问不算回看 |

展示按分钟简写，小于一分钟显示“不足 1 分钟”；原始数据保留精度，先求和再格式化。不同层级的时间范围和单位始终可见，不在每张卡片反复解释估算规则。

日期按阅读发生时记录的当地自然日归属，午夜分界；跨午夜切开汇总，完整阅读过程仍可在详情串联。月历的周起始跟随系统日历习惯。后续跨时区不会重分已有片段的历史日期，不增加凌晨跨日设置。

## 日期与单书详情

**日期详情**从节奏图点按某天进入：当天总时长、钟点时段图（一行对应一本书，一段横条对应一次连续有效停留，时轴按当天实际时段展开）和各次阅读列表，长按单次记录可删除。相邻检查点只在同会话、正文、日期、时区和正式/查阅类型均相同且无间隙时合并。暂停形成的空隙不涂满；同名不同正文保留独立行。从单书详情进入时只显示这本书。

**单书详情**可从统计书目行、书架书籍菜单和最近阅读菜单进入，复用原生导航。先显示小说信息、我的阅读和累计时长/阅读日数/首次与最近阅读；其下是与首页语义相同的时间范围，从统计进入时沿用所选范围，其他入口默认近 7 天。范围内显示期间时长与阅读日、对应节奏图（月范围为本书阅读日历），以及默认收起的“阅读时段”：范围内最近 7 个阅读日的钟点图与各次阅读。选择“全部”时仍显示范围选择，只省略与累计重复的期间数字。没有章节分析的占位数字，不推断读完本数、速度或读完日期。

第一版不把笔记数量堆进首页。单书详情可显示当前书签、标注/笔记数量并链接原有工具；这是当前存量，不能写成“本周新增”或由数量推断阅读深度。统计日期下的操作历史另有需要再设计。

当前统计页面只查看数据，不自动打开正文；原文件删除后历史仍可查看。历史位置临时浏览与章节分析一并后续接入。

## 章节覆盖与重复阅读

章节目录已在字数下显示覆盖，详情显示当前章摘要；正文分布和回看次数仍未实现。需要分开三件事：

- **当前位置**：目前停在本章哪里，跳转会改变位置。
- **覆盖范围**：真正显示并满足有效停留规则的正文范围并集。跳到 80% 不代表前 80% 都读过。
- **重复访问**：离开某处再返回并阅读；一次连续停留、边界来回微调、重排和重复视口回调不增加次数。

覆盖包含正式阅读和临时查阅，范围相互去重。使用稳定正文坐标及[章字数口径](book-details.md#计算与边界)：排除标题与空白，包含标点，按非空白 Unicode 字符数计算，不用字节比例或随字号变化的页码。修改目录边界后重算归属；正文 SHA 变化不套用旧覆盖。有效再次访问的计次仍由后续分析处理。

滚动中一屏出现过不等于整屏读完，需要结合可见范围、停留和用户驱动的连续阅读；快速拖动和跳转跨过的内容不能自动补全。[参考源码核对](../research/readers.md#停留快滑慢滚与回看)显示 Readest 默认过滤不足 3 秒的页事件，KOReader 默认为 5 秒；两者按页统计，不能直接用来计算月读原文范围覆盖。

月读已确认并接入连续可见 3 秒的覆盖门槛。慢滚的重叠原文范围延续停留，不因每次滚动或数据库检查点而重置；离开后短时间再次掠过不相加冒充连续停留。3 秒不丢弃正常阅读时长，120 秒仍是闲置上限。回看边界及部分重叠计次仍待后续实现，不能承诺逐字准确。

已确定章节覆盖、回看与时长共用阅读事实：暂停记录后既有结果保留，不再增加；清理单次、单书或全部统计后按剩余事实一起重算。不另存一份不受清理影响的权威章节百分比，也不联动删除小说信息、封面、书签、批注、正式续读或手动阅读状态。

正文分布图借鉴 Book Map 的用途，按章节及正文位置展开，支持“累计停留／回看次数”切换，不让同一种颜色同时表示两件事。点选区域展示文字定位摘要、最近访问与次数，再进入临时浏览。图形有数值图例和列表替代，不只靠深浅识别。描述使用“回看 3 次”，不推断“完整读了 3 遍”。

默认章节覆盖看累计，期间时长看当前范围并明确标注；若提供期间覆盖视图，必须显式切换。正文还在渐进准备、当前章终点未知时先显示已知时长/范围，不输出会随导入任意变化的百分比。100% 覆盖也不自动标记整书读完。

## 什么时间算阅读

| 场景 | 处理规则 |
| --- | --- |
| 前台可交互且正文可读，翻页/慢滚/静止读文字 | 计时；静止仍受闲置上限约束 |
| 锁屏、自动熄屏、后台、scene inactive（例如控制中心） | 立即暂停，恢复后不补算离开期间 |
| 封面、下载、尚无可读正文、错误页 | 不计时 |
| 正文可读，后续内容后台准备 | 正常计时，不受后台解析进度影响 |
| 目录、搜索结果、工具面板、设置、笔记编辑器 | 暂停正文计时；文字选区本身仍是正文交互 |
| 正文中的临时浏览 | 可读正文满足相同停留规则就计时，并入总量；保留“查阅”类型，不改续读和最近阅读排序 |
| 从这里继续读 | 此刻起转为正式阅读，不追溯改写先前查阅；此前已计时的查阅不重复累计 |
| 重排、窗口补块、恢复位置、数据库保存 | 不刷新闲置额度；正文不可读的转场不计时 |
| 设置里的阅读预览 | 不生成书籍统计 |

最低亮度或深色主题不等于锁屏。使用阅读所属 scene 与正文可见性，不靠 App 是否运行、`onDisappear` 或全局 Timer 判断。

**闲置阈值**指正文亮着但一直没有滚动、翻页或正文操作时，多久后暂停累计阅读时间，用来避免手机放着不看却一直计时。它不适用于锁屏和后台：这些情况立即暂停。

**已确定：120 秒。** 最近一次明确正文交互后，最多累计 120 秒有效正文停留，然后暂停；之前已计入的时间保留。再次滚动、翻页或操作正文恢复，不补闲置、不弹确认提示。暂停在系统/面板中的时间不消耗剩余额度；关闭面板、同步、恢复前台不自动重置已经耗尽的额度。主动重新开书视为新阅读意图。

这会少计特别慢的一页，也可能多计放下手机后的前两分钟。仅在统计说明中解释估算，不用摄像头或目光检测。120 秒是月读确定的产品规则，不是 Apple 标准；不再将时长或慢读选项列为本轮待确认项。

## 原生布局、动效和状态

- 使用现有原生导航、Tab、列表、菜单和系统搜索；图表优先 [Swift Charts](https://developer.apple.com/documentation/charts)。颜色、字号、间距来自主题；统计分类色定义在主题层（`ThemeSurface`），按明暗共用，不随预设或自定义配色变化。
- 图表的有效数据、空白和选中不能仅依靠颜色区分。为 VoiceOver 提供日期、时长、总计及等价列表，支持大字号；依据 [Apple Charts](https://developer.apple.com/design/human-interface-guidelines/charts)。
- 切周期保留已有内容直到查询完成，图表按新数据更新，不加长数字滚动或整页重播动画；详情走原生导航。
- 首次无数据说明“开始阅读后显示统计”，不能编造过往时长；尚未启用记录、真实零阅读、数据加载中、同步未完成是不同状态。
- 沿用加载规则：已有统计保留可见，局部刷新短暂延迟指示；无内容的慢页面立即显示整页等待。计算查询不阻塞正在阅读的正文。
- 统计首页和单书详情支持顶部下拉刷新：首页重新计算统计；单书详情先刷新书架文件索引，再重读小说信息与下载状态，最后计算该书统计。规则见[下拉刷新](library.md#下拉刷新)。
- 已提供全局暂停记录与清理单次/单书/全部记录。单次清理针对一次开书产生的所有片段，确认时明确范围。清理不动原文与阅读工具数据；本地旧写入不能复活删除。同步清理边界已建模，真实双设备传播尚未验收。

## 参考补充与取舍

| 补充 | 放在哪里 / 采用建议 |
| --- | --- |
| 日期内的小时分布、当日书目和时间线 | 放在点按某天进入的日期详情，首页只保留日节奏图 |
| 单书阅读日历、首次/最近日期 | 纳入单书详情 |
| 正文分布图结合书签、标注定位 | 纳入深入分析阶段；默认只展示一层统计，书签/标注按需显示 |
| 样本不足时隐藏速度 | 采用原则；阅读速度保持后续候选，不扩展为预计读完时间 |
| 统计同步去重 | 纳入数据设计；不照搬参考项目的账号或外部同步服务 |
| 将凌晨阅读归前一天、自定义一天起点 | 不采用；已确定使用阅读发生地自然日和午夜分界 |
| 速度排名、目标/打卡、导入外部统计 | 暂不加入本次主范围；数据不足不伪造数值 |

## 当前采集与保存

Swift 上报正文可见性、实际交互、场景状态、单调时间和墙上时间；Rust 负责闲置、切片、跨午夜、覆盖与聚合；SwiftData 持久化事实。每秒采样可见 UTF-8 范围，正文交互最多每秒 4 次通知且不重复解析视口；每 15 秒输出一个不可变片段，暂停/离开及时结算。稳定片段 ID 保证重试不翻倍。强退只保留已落盘记录，不把下次打开前的间隔算作阅读。

片段保存在 SwiftData `ReadingFact`，包含正文身份、会话、连续访问 `visit_id`、设备、UTC 起止、发生地自然日/时区、正式或查阅类型、可见范围停留证据。SHA 完成前按临时身份保存，正文完成后从设备存储转入 SHA 正式用户存储。覆盖查询根据连续范围和 3 秒门槛派生，不把原始可见范围直接作为已读。

阅读记录设置用独立 generation 阻断清理前的迟到写入；失败保留原 ID 重试，有界队列积满时暂停新增记录，并在统计页显示错误。数据库版本统一见[数据结构](../data/README.md)，后续持久化变更须带版本与迁移测试，不能清空统计代替升级；外部及云目录原件不随迁移改写。真实设备的锁屏/长时性能、辅助功能及跨设备验证边界见[验证记录](../engineering/verification.md)。

计时平台依据：[ScenePhase](https://developer.apple.com/documentation/swiftui/scenephase)、[失活时暂停与保存](https://developer.apple.com/documentation/uikit/uiscenedelegate/scenewillresignactive(_:))、[ContinuousClock](https://developer.apple.com/documentation/swift/continuousclock)。Apple Books 提供阅读分钟和目标功能，但[公开说明](https://support.apple.com/guide/iphone/set-reading-goals-iph6013e96f4/ios)没有公布可照搬的闲置算法。

统计片段和计时器只携带书籍身份，不携带书名。保存时由 Rust 根据身份读取书籍标题并写入历史记录；暂停、恢复或清理后重建计时器沿用同一规则。

经过时长使用单调时钟、日期使用墙钟。ContinuousClock 在睡眠期间仍前进，失活时必须结算，恢复建立新基准；系统时间变化只重新锚定展示时间，不改已累计时长。强退仅保留成功落盘记录，正常存储条件下最多损失一个15秒检查点，不承诺任意失败零丢失；迟到回调仍按闲置截止时间截断。测试注入时钟，避免用真实长等待验证状态机。
