# 动效、启动衔接与月亮组件

状态：2026-10-05 已实现启动画面、书架原生导航标题过渡、原生加载提示、设置与阅读作用域的动效偏好。所有等待均使用系统 `ProgressView`：无内容的整页等待为居中大号转圈，局部为小号转圈，已知比例为线性进度条；月亮不再表示等待。阅读助手采用「月光」：固定品牌色的深蓝圆盘与暖金月亮，只按任务状态改变亮度、月相与角标，没有五官、道具或弹跳。内置书架使用系统 `books.vertical` 符号。2026-10-16 桌面图标由「月印」字标改为「夜读」（见[应用图标](app-icon.md)），启动图、关于页与扉页这些品牌位置随之统一。现状见[样式盘点](ui-inventory.md)，母版见[应用图标](app-icon.md)。

## 动效应表达什么

目标是让用户看懂“从哪里进入、当前状态怎样变化、关闭后回哪里”，保持阅读正文稳定。已有原生导航、翻页、键盘和 sheet 动画继续复用，不全局给每次状态更新套动画。

| 场景 | 建议表现 | 约束 |
| --- | --- | --- |
| 书架导航标题 | 恢复原有原生紧凑标题和系统导航行为 | 删除胶囊、大标题替代方案与自定义显隐逻辑；特殊滚动收起效果尚未实现，本次不追加动效方案 |
| 书架进入阅读/返回 | 保留原生导航，仅已显示慢准备扉页时淡入正文 | 内容一就绪就读，不等待片头；返回可取消，不能重复导入 |
| 阅读工具显隐 | 淡入/淡出并轻移，沿用现有约 0.22s 的基础 | 只动覆盖层，不缩短正文、不移动行 |
| 底部快捷内容切换 | 面板高度 0.20s 平滑变化，内容立即交叉淡变 | 底部四列入口固定且不淡出；文字不缩放，快速切换可打断。详细参数见[阅读弹层](reader-panels.md) |
| 搜索药丸/详情 | 保留同一个原生 sheet、detent 和连续内容渐变 | 不关闭后新开另一个 sheet，保留查询、结果和列表位置 |
| 快捷区进入目录/历史/批注 | 保留同一 sheet 和起始高度档位，连续扩展并切换内容 | 关闭直接回到正文或必要药丸，不重新弹出四列工具；从“更多”打开的书签/笔记列表收回“更多”；完整设置只播放页面导航 |
| 批注与键盘 | 系统协调打开/关闭；输入焦点在转场完成后交接 | 不在关闭结束后再补一次定位或焦点动画 |
| 书签、选项选择 | 原生按压反馈；图形/选中底短暂变化 | 不因小操作弹整页 toast，不移动正文 |
| 删除与撤销 | 行删除/恢复使用系统列表转场，撤销辅助条淡入 | 记录删除语义和红色操作不被可爱装饰弱化 |
| 主题预览/应用 | 同一画面的颜色原子更新，必要时做短暂整体淡变 | 不逐角色错峰改色；光暗切换中若混色降低可读性则直接切换。正文布局、选区和锚点不变 |
| 设置页 | 原生选择与导航反馈 | 不强行左右滑动整页，不改变当前阅读位置 |
| 真正加载/空态 | 加载用系统转圈；已加载的空态可用静止月亮 | 空态不伪装成仍在加载，失败/暂停移除转圈并有可执行动作 |
| App 启动页进入首页 | 屏幕中央 120pt 桌面图标由系统静态启动图接续到 App 首帧，与底色一起在 250ms 内原地淡出 | 主题与本地首页快照就绪即开始，最多等待 1s，无额外停留；减弱动态时缩短至 120ms，回前台不重播 |
| 空白等待页进入内容 | 居中大号系统转圈淡出；内容就绪即显示、可操作 | 只动画覆盖层；不等待退场结束再显示内容 |

### 共同动效参数

`MotionTokens` 当前包含减少动态 100ms、工具 180ms、快捷内容/任务切换 200ms、搜索面板 240ms 和配色 180ms；工具位移 12pt。快捷内容进入 120ms、移除 80ms，无延迟。参考应用源码依据见[阅读器对照](../research/readers.md)；这些是本应用配置时长，不冒充实机逐帧测量。系统导航、sheet 和键盘转场由系统计时，不叠加固定延迟。

减弱动态优先级：`系统减弱动态 OR App 选择减少动效`。开启时移除旋转、缩放与大位移，必要的短淡变或直接状态切换保留；后台、离屏、无活动任务时停止持续动画。把动画挂在局部状态，避免导入轮询、时间/电量更新触发全页动画。[Apple Reduce Motion](https://developer.apple.com/documentation/swiftui/environmentvalues/accessibilityreducemotion)

## 月亮的角色

月亮用于品牌、空态与阅读助手，不表示等待：

| 含义 | 位置 | 形式 |
| --- | --- | --- |
| 品牌 | 桌面图标 | 「夜读」：深蓝夜空、暖金弯月与两颗星，下方一本翻开的书 |
| 品牌 | 启动页、关于页、阅读扉页（无封面时） | 深蓝圆角品牌方块（`BrandSeal`），与桌面图标一致 |
| 角色 | 阅读预览样例 | 「月光」空闲状态：深蓝圆盘里的细月 |
| 空态 | 空文件夹、对话列表与空对话 | 「月光」空闲状态配一句简短状态 |
| 阅读助手 | 阅读页可拖动月亮 | 按真实任务状态改变月光亮度、月相和角标，阅读时只短暂出现，见[AI 阅读助手](ai.md#阅读月亮入口) |

对话 Tab 使用标准 `bubble.left.and.bubble.right`，不用月亮：弯月符号常表示夜间、睡眠或勿扰。夜间/明暗开关同样不用月亮。

## 加载与真实进度

- `MoonView`：「月光」空闲状态（深蓝圆盘里的细月，几何与桌面图标的月亮一致），用于空态与阅读预览样例；与阅读助手共用同一绘制，使用固定品牌色，不承担加载动画。
- `LoadingActivity`：默认使用系统 `ProgressView`，未知进度为圆形等待、已知进度为线性进度条；需要百分比的下载保留真实数值。显式指定 `fullPage` 的整页未知等待使用居中大号转圈（`PageSpinner`），屏幕上不加“加载中”文字，标签仅供 VoiceOver。组件只负责表现，不启动导入或搜索任务。
- 全文搜索已知扫描总量：详情状态栏与收起后的药丸均用 `scannedUtf8 / availableUtf8` 驱动原生进度条，无障碍名称为“搜索进度”。药丸为图标或进度条保留相同宽度。局部指示延迟 300ms；停止或结束搜索后移除提示，保留已有结果。新查询从零开始。导入中搜索的总量是本次冻结的已准备内容，不能把它当作尚未导入的全书进度。
- 状态为 `idle / indeterminate / determinate(fraction) / paused / failed`。同一位置只保留一个进度表达，不叠加转圈和进度条。
- `DeferredLoading` 默认只对辅助指示使用 **300ms** 防闪烁延迟，由 `LoadingTiming.inlineDelay` 管理；`.zero` 从首帧显示。该数值是月读的体验参数，不是苹果规定。任务、按钮和导航响应始终立即发生，不强制最短展示时间；错误与暂停操作状态立即显示。
- 页面查询由 `LoadingState` 标识每次请求，旧任务完成不能清掉新任务的提示；`PageLoadingOverlay` 无内容时立即居中显示大号系统转圈，已有内容更新时延迟显示导航栏 20pt 系统转圈，不覆盖“最近阅读”“查看全部”等列表内容。明确点击刷新、登记新书架、已知下载和批量导入立即反馈。内容就绪即移除提示，导航和已有内容继续可用。已有外层延迟的组件内部不重复计时。
- 输入、按压、导航立即响应；目录筛选保留旧结果与稳定视口，新批次就绪后原子替换，不先清空制造空屏。旧查询结果在等待新查询时不可跳转，避免误选。仅聚焦空搜索框不触发查询；清除查询回到当前章。
- 系统转圈与进度条遵循原生减少动效行为，保留真实状态/进度语义；独立装饰图隐藏于无障碍树。

SVG 保留为源文件，导入 Xcode 图片资源后用原生 Image 绘制；不引入 WebView、Lottie 或通用 SVG 运行库。Xcode 支持 SVG 图片资产，具体几何特性仍需 asset catalog 编译验证。[Xcode SVG 支持](https://developer.apple.com/documentation/xcode-release-notes/xcode-12-release-notes/)

### 等待入口覆盖

| 场景 | 表现与结束条件 |
| --- | --- |
| 首页、目录、全部小说、最近阅读、移动目标 | 无内容时立即显示大号系统转圈，已有内容则延迟显示导航栏系统转圈；已知列表不清空；返回或新请求替换后移除对应提示 |
| 手动菜单刷新／后台目录扫描 | 手动刷新立即反馈，自动后台扫描静默进行；系统下拉刷新沿用原生指示，避免重复 |
| 文件名搜索 | 无结果可显示时用大号系统转圈，已有结果时用系统转圈；旧结果暂不可选，新结果就绪后原子替换；取消清除等待 |
| 原文件下载／获取 | 已知下载立即在对应书籍封面内显示原生进度条＋真实百分比，未知比例显示系统转圈；本地访问检查采用局部延迟。点按取消，不替换更多按钮或改变书目布局，完成后进入正文准备 |
| 目录／笔记首次查询 | 整页无内容时用大号系统转圈；追加分页时用局部系统转圈 |
| 目录预览追加、应用目录、百分比及阅读目标定位 | 局部系统转圈；只在真实任务期间显示，不以空态代替等待；定位时保留原正文，覆盖提示不改变文字视口 |
| 设置初次读取 | 保留已可用设置，延迟显示导航栏系统转圈；读取完成即移除 |
| 导入、复制、移动、删除、导出 | 导入和批量操作立即显示系统转圈，批次连续反馈，等待替换选择时暂停；短小单次操作只延迟辅助转圈。没有可量化字节进度时不估算比例 |
| 正文准备底部状态、全文搜索、目录重建 | 原生进度条表达真实处理比例；后台准备不遮挡可读正文 |

iCloud 下载采用 [NSMetadataUbiquitousItemPercentDownloadedKey](https://developer.apple.com/documentation/foundation/nsmetadataubiquitousitempercentdownloadedkey)，其单位为 0–100；用 [searchItems](https://developer.apple.com/documentation/foundation/nsmetadataquery/searchitems) 限定当前文件，取消及完成时停止查询。未知、越界和非有限值均不能冒充确定进度。iOS 不支持 `Progress.addSubscriber(forFileURL:)` 的跨进程订阅 API；不为第三方提供方伪造通用字节回调。下载和正文处理的比例分属两个阶段，不混成一个百分比。

### 规范依据与取舍

Apple 强调尽早显示可用内容、允许后台加载；能量化时优先确定进度，进度须准确、位置稳定。局部已知进度选择原生线性样式：圆形样式在部分平台不支持确定进度，会退回无限等待。Apple 没有给所有场景规定一个毫秒门槛；后台小任务建议使用不打扰的转圈，转圈不加说明标签。[Apple Loading](https://developer.apple.com/design/human-interface-guidelines/loading)、[Apple Progress indicators](https://developer.apple.com/design/human-interface-guidelines/progress-indicators)、[SwiftUI CircularProgressViewStyle](https://developer.apple.com/documentation/swiftui/progressviewstyle/circular)

NN/g 与 IBM Carbon 均强调按等待场景选择反馈，短任务的循环动画可能造成闪现和分心。月读将无内容的新页面、明确长任务与保留内容的后台更新分开：前两者立即反馈，后者仅对辅助指示设置 300ms 防闪烁延迟；按钮、输入和任务启动不等待计时器。[NN/g](https://www.nngroup.com/articles/progress-indicators/)、[Carbon Loading](https://carbondesignsystem.com/components/loading/usage/)、[Carbon Inline loading](https://carbondesignsystem.com/components/inline-loading/usage/)

月光助手为 40pt 深蓝圆盘，56pt 画布，暖金弯月与桌面图标共用两圆相减的几何；颜色固定，仅外沿间隙取阅读纸色。完成时月相在 0.4s 内渐盈，工作光晕以 3s 周期呼吸；减弱动态时使用静止状态。`.icon` 包不作为 App 内图片资源读取。

## 启动和白屏分层处理

这里的启动页指点开 App 时的第一屏，与目录、搜索等空白加载页分开。系统 Launch Screen 只能静态显示，运动由 App 的第一帧接续；不增加固定等待时间。[Apple Launching](https://developer.apple.com/design/human-interface-guidelines/launching)、[启动画面配置](https://developer.apple.com/documentation/xcode/specifying-your-apps-launch-screen/)

1. **系统 Launch Screen**：使用浅深 `LaunchBackground` 与静态 `LaunchSeal`，以全屏中心定位。图片为 120pt 的桌面图标本身：用 `ictool` 从 `assets/icon/Moonread.icon` 以 Default 外观导出 1x/2x/3x（120/240/360px）PNG，打开应用时从刚点按的图标接续；无文字、转圈或虚假进度。App 首帧使用同一资源。[启动屏调试说明](https://developer.apple.com/documentation/technotes/tn3118-debugging-your-apps-launch-screen)
2. **App 首帧**：独立 `MoonLaunchCover` 使用同一资产、尺寸、位置和系统浅深背景，放在 App 主题容器外，避免交接时换成另一种图形。读取主题的同时准备本地 HomeSnapshot，二者就绪或错误、或根等待到 1s 上限后，底色和图标一起原地淡出；封面预热共享 150ms 子预算。具体边界见[首页](library.md#本地首屏与后台刷新)。启动衔接立即显示，不延长真实准备时间；错误时退出覆盖层并显示重试。返回首页或后台回前台不重播。后续目录刷新按上述内容可用性规则显示 loading，不清空已有书目。
3. **开书准备**：背景从一开始使用解析后的阅读纸色，复用带书名和品牌图标的扉页；底部准备状态使用原生进度条或转圈，配必要暂停/重试动作。快开直接显示，不出扉页、不淡入；push 完成且本地准备满 300ms 才显示扉页，满 800ms 才显示进度和暂停，仅已经展示扉页后就绪才局部淡入 200ms，减弱动态直接替换。计时及取消见[开书流程](../reader/import.md#慢开书展示与会话契约)。后续准备继续后台进行。
4. **已可阅读**：后台索引不常驻整页等待。只有读到准备边缘或展开准备工具时显示低干扰状态，保持现有最大正文空间。

系统启动页无法运行 Rust、读取任意自定义主题并执行动画。启动覆盖层跟随系统浅深，下面的首页从可丢弃的主题快照恢复上次配色，再由核心设置校正；选择了与系统不同的主题时，通过覆盖层淡出衔接。系统可能保留旧启动快照，仍需分别检查冷启动、热启动与系统切换；不得使用固定等待时长掩盖主线程阻塞。

## 验收重点

录看真实转场而非只截两张图：冷/热启动与开书、快任务无闪现、未知/已知进度、暂停/失败/取消、减少动效、App 与阅读反向明暗、搜索收展、带键盘批注关闭。持续动画只在可见工作中运行；改主题和进出工具后正文 glyph、页边界、选区与保存锚点保持不变。所有等待都有真实任务依据，不为品牌展示制造延迟。
