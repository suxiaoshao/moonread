# 打赏

状态：已实现。付款验证证据见[验证记录](../engineering/verification.md)，商品和分发核对见[发布手册](../engineering/release.md)。

## 目标与原则

给愿意支持的用户一个主动进入的打赏页面，不打扰其他读者。

- **打赏不换取任何东西。**所有功能保持免费，打赏不解锁功能、不显示徽章，也不区分“支持者”。
- **只在用户主动寻找时出现。**阅读器、书架、使用指南和首次引导里都不放入口。不弹窗，不在读完一本书或使用一段时间后提醒，也不发通知。
- **不收集数据。**打赏只经过 Apple，月读不记录金额、次数或打赏历史，不需要服务器。

## 入口

设置页最后一组，放在“关于月读”下面，名称为“支持月读”：

```
设置
  …
  关于月读        当前版本
  支持月读
```

- 图标使用 SF Symbol `heart`，右侧不显示摘要。
- 不放进“关于月读”页面里，因为藏得太深，用户需要点两层才能找到。

## 页面

页面标题为“支持月读”，内容从上到下：

1. 月光形象（空闲状态）和两句说明：“月读没有广告，也没有自己的服务器，你的书和阅读记录只留在你的设备和 iCloud 里。”
2. 四档打赏，每档一行：左边是名称和一句说明，右边是价格按钮。

   | 商品 ID | 名称 | 说明 | 基准价（USD） |
   | --- | --- | --- | --- |
   | `dev.moonread.tip.star` | 一颗星 | 一点小小的心意 | USD 0.29 |
   | `dev.moonread.tip.tea` | 一杯茶 | 谢谢你读到这里 | USD 0.99 |
   | `dev.moonread.tip.snack` | 一份夜宵 | 陪作者熬一个晚上 | USD 2.99 |
   | `dev.moonread.tip.book` | 一本书 | 让月读继续写下去 | USD 6.99 |

3. 底部一行小字：“打赏不会解锁任何功能。付款由 Apple 处理。”

页面配色跟随应用外观：背景、卡片、文字和价格按钮都使用当前主题的 `canvas`、`surface`、`ink`、`secondary`、`accent`，不使用系统默认的蓝色按钮和灰色分组背景。

价格一律显示 StoreKit 返回的 `displayPrice`，不在代码里写死金额，其他地区自动显示当地价格。表中基准价是 2026-10-16 的产品决定，当前价格和供应地区以 App Store Connect 为准；文档不构成调价或开放地区授权。

### 付款状态

- **购买中：**价格按钮显示系统转圈，其他三档暂时不能点。
- **成功：**月光播放一次“完成”动画（盈满），说明文字换成“谢谢你的支持”。几秒后恢复原样，可以再次打赏。不弹提示框。
- **用户取消：**没有任何提示，按钮恢复原样。
- **等待批准**（家长批准购买、银行额外验证）：显示“已请求批准，批准后会自动完成”。pending 只表示本次停留期间的请求：同一商品重试前清除，离开打赏页时全部清除，离页后才返回的 pending 不再显示；被拒且没有交易回调时不跨页面残留。批准后的交易仍由应用级后台监听处理并感谢，不持久化等待状态。
- **失败：**在该行下方显示简短原因，可以重试。
- **商品读取失败或离线：**四档位置显示“暂时无法连接 App Store”和“重试”按钮。入口始终保留，不因读取失败而隐藏。

## 技术方案

- 使用 StoreKit 2，最低系统 iOS 18 可直接用，不引入第三方库。
  - 读取商品：`Product.products(for:)`；
  - 购买：SwiftUI 环境里的 `purchase` 动作。
- 四个商品都是**消耗型**项目。消耗型项目不能“恢复购买”，所以页面上不放恢复按钮；它也不参与家人共享。
- 交易处理：
  - 应用启动时开始监听 `Transaction.updates`，接住在后台完成的交易（比如等待批准、中途被打断的付款）。
  - 只有通过系统验证（`.verified`）的交易才 `finish()` 并显示感谢；未通过验证的交易不显示感谢，只记日志。
  - 监听器生命周期跟随应用，不跟随页面。
- `TipJar`（`@Observable`）负责读取商品和处理交易，页面只负责显示，商品读取由它持有单一 Task，不随页面取消；未 ready 时进入页面会等待已有读取或新建读取，结果更新 ready／unavailable，完成后释放任务。失败后再进入自动重试，ready 不重复读取。
- 文字放进 `Localizable.xcstrings`。商品名称和说明同时在 App Store Connect 中按语言填写。

## 边界与验证

只用 Apple 应用内购买，不加外部付款链接、订阅、付费功能、排行、支持者标记或主动提醒。付款由 Apple 处理，App 不维护购买历史。AI 主动发送的第三方数据边界单列在[隐私政策](../../site/content/privacy.md)，不把书和阅读记录的存储说明扩成所有功能离线。

Swift 测试只保护本机付款状态和业务边界，不测试真实 StoreKit/账号；付款联调在明确授权的沙盒环境另验，不作为每 PR 单测依赖。历史 StoreKitTest 通过不证明当前真机沙盒或正式交易通过。
