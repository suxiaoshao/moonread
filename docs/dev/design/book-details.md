# 小说详情与章节阅读百分比

状态：2026-10-01，本地功能已接入，实际验证见[验证记录](../engineering/verification.md)。小说信息和单书统计共用详情，支持信息编辑、作者/标签筛选及章节累计估算覆盖。封面 SwiftData 外部存储与自动同步已接入，签名与真实云端证据见 verification；回看次数和正文分布尚未实现，统计事实已接入自动同步，真实双设备仍待验收。

## 一个详情页面

原生导航页面依次展示小封面、完整书名、作者、已知字数/章节数，其下为通栏的主题实心主按钮“开始阅读／继续阅读”（从阅读进入时为“返回阅读”），再显示标签和简介，再显示我的阅读、累计时长/天数/日期，然后是与统计页语义相同的时间范围（期间时长与阅读日、节奏图或月历、默认收起的阅读时段），文件信息默认收起，整书「清除阅读数据」放在详情最末；从阅读器进入时隐藏该操作。

详情允许书名换行，封面约 64×90pt。阅读按钮下方提供“补全资料”和“找封面”：标准字号一行两个，辅助功能字号纵向排列、各占一行。标签自动换行，标签与简介字号不高于作者行，展开简介在正文下方左对齐。没有作者、标签或简介时省略对应内容，不放占位提示。作者筛选、标签筛选和阅读按钮分别响应点击，不将整行自动变为链接。统计入口继承期间，首次定位到我的阅读；切换期间不再次自动滚回。

## 哪些内容允许编辑

| 字段 | 规则 |
| --- | --- |
| 作者、简介 | 文本，可修改或清空；不从文件名猜测，不自动联网抓取 |
| 标签 | 平面文本，可添加/移除，去首尾空白和重复项，提供已有标签候选 |
| 封面 | 系统照片/文件选择器选择、更换或移除；移除恢复主题文字封面 |
| 阅读状态 | 首次正式阅读从未读变为阅读中；按正文 SHA 的阅读位置记录投影，只有有效索引身份、尚无本机正文缓存的书也适用；读完/暂搁手动设置，也可手动恢复阅读中；重读保留读完标记 |
| 文件名、路径 | 菜单复用真实重命名/移动，独立提交，不在补充信息表单中维护别名 |
| 字数、章节数、续读位置、覆盖、时长、日期、文件属性 | 来源于正文、阅读事实或文件系统，不允许手工填写数值 |

查阅、打开详情、为编辑准备正文和覆盖 100% 不自动标记读完，也不刷新正式续读和最近阅读。补充信息与状态属于正文 SHA；清理统计不删除手动状态。

## 小说信息编辑

详情菜单提供“编辑小说信息”。原生表单顺序为封面、作者、标签、简介，使用 × 取消和 ✓ 保存，并保留明确的无障碍名称。

- 草稿仅属于本书的本次编辑；保存一次提交变更字段，取消不写原值。
- 有修改时禁止直接下拉关闭；取消按钮使用原生放弃修改确认。保存时禁用表单，失败保留内容。
- 点击非输入区域收起键盘；关闭后的图片回调不会保存新草稿，旧选图回调不覆盖新选择。
- 保存只等待本机可靠提交，云端按现有同步开关随后上传。
- 仅提交相对打开表单时实际修改的字段，保留期间同步到达的其他字段；标签按成员增删合并。

### 作者与标签筛选

作者与标签都是搜索的 token：详情中点按作者或标签，在当前导航栈推入带该 token 的情境搜索，可再输入文字或移除 token 搜索全部；返回键回到这页详情。从阅读页进入的详情同样可用：搜索推在详情之上，原阅读会话暂停不结束；选另一本书在其上打开，选正在读的这本书直接回到原书。详见[找书与搜索](library.md#找书与搜索)。

筛选只读取已保存信息，不自动下载或处理整库。作者按文本匹配，不增加作者实体/别名、标签树、独立 Tab 或虚拟书架。文件夹本身没有作者和标签。

## 封面如何保存

封面为 SwiftData 外部存储数据与不可变资源引用，归完整正文 SHA；不改 TXT，不向原目录写旁车文件。用户主图不是缓存。

| 内容 | 位置与生命周期 |
| --- | --- |
| 主图 | `UserCover.bytes` 的 `.externalStorage` 属性，由 SwiftData 管理邻接附件 |
| 引用 | SHA 下的元信息字段保存资源 ID、图片 SHA、格式和尺寸 |
| 缩略图/读出副本 | 本机可重建缓存；删缓存不影响用户主图 |
| 选图草稿 | 应用临时目录；保存先写入附件，再事务提交引用，取消清理草稿 |
| 云端 | SwiftData 自动同步附件；未到达时用文字封面，不另建上传队列 |

PhotosPicker/系统文件选择器取得图片后，由 ImageIO 校正方向并降采样，主图最长边 1600px；不透明图保存 JPEG，含透明通道图保存 PNG。保留主图比例，封面框居中展示，首版没有手动裁切、旋转或滤镜。重新编码不保留定位等无关原图元数据。

替换使用不可变资源 ID；失败保留旧引用，附件暂缺时使用文字封面。缓存副本可从 SwiftData 重新读出。封面引用与附件可能分批到达：文字封面先显示，不阻塞开书。封面业务加载层提供等待/加载/可展示状态并共享请求，监听 SwiftData 保存、持久存储远端变化与 CloudKit 导入完成事件；附件到达后同一书架/详情视图自动换成图片。页面不猜重试时间。缓存按资源 ID、内容哈希和尺寸区分，旧资源或取消请求不能回写新状态。本地保存通知与真实云附件事件的验证边界见[验证记录](../engineering/verification.md)；不能把本地事务当作云端多记录原子提交。

作者、简介、标签、状态与封面跟随阅读数据同步开关，原 TXT 继续走 iCloud Documents。字段修订与标签成员合并复用已有同步机制。Swift 管理图片与平台传输，Rust 管理正文身份与计算，SwiftData 业务层管理字段、引用与合并。

平台依据：[Apple 文件目录](https://developer.apple.com/library/archive/documentation/FileManagement/Conceptual/FileSystemProgrammingGuide/FileSystemOverview/FileSystemOverview.html)、[PhotosPickerItem](https://developer.apple.com/documentation/photosui/photospickeritem)、[SwiftData 外部存储](https://developer.apple.com/documentation/swiftdata/schema/attribute/option/externalstorage)。云端边界见[iCloud 接入实施](../data/sync.md)。

## 入口统一

| 来源 | 行为 |
| --- | --- |
| 书架、网格、全部小说、最近阅读、搜索结果 | 单本菜单/长按菜单 → 小说详情；主点击仍开书 |
| 统计书目 | 同一详情，继承期间并定位到我的阅读 |
| 阅读页显示工具时 | 页面右上角 info.circle，与返回按钮同一行；底部“更多”的“详情” |
| 起始页 | 信息摘要下方的小说详情按钮 |

普通书架保留 Tab；阅读来源继续隐藏 Tab。作者/标签筛选在详情所属导航中进入，不同时改写底层阅读路径。文件操作沿用真实来源授权；缺少原文时仍可看已有阅读信息，不另建恢复关联流程。

## 阅读弹层中的信息按钮

信息按钮放在阅读页右上角，与左上角返回按钮对称，使用主题 ink，随阅读工具一起显隐；底部“更多”的最后一项“详情”是有意保留的第二个入口，从详情返回回到“更多”。目录、书签与笔记列表内不重复。底部进度、快捷设置及搜索/临时浏览药丸不追加详情按钮，保留原有进度与四列工具。阅读页交接现有 sheet 后进行原生导航，保留会话、查询、临时浏览原点与面板上下文。

详情暂停正文计时，不触发退出阅读保存及会话回收。返回恢复原上下文；取消返回继续留在详情。从阅读进入只显示“返回阅读”，退回已有阅读器；其他来源沿用正常下载/开书流程。

## 小说起始页只展示摘要

保留一页扉页及原翻页/滚动手势，展示书名、可用封面/作者、已知字数/章数、最多三个标签和两行简介，提供详情入口。摘要区域预留高度，信息补齐不改变正文布局或分页边界。

起始页不放统计图、文件路径或编辑表单；续读不强制经过起始页。扉页不参与原文坐标、字数或阅读时间；展示摘要不会强制完成全文准备。

## 章节列表里的阅读百分比

章名较短时，章名在左，右侧同一行一条次要说明合并精确章字数与累计估算覆盖，例如 `10,818 字 · 已读约 94%`；章名放不下时改为最多两行，说明移到章名下方，不挤压或截短章名来容纳数字。字数不取整为“万”，100% 仍写作 `已读约 100%`，不增加“已读完”标记。完整计数且覆盖恰为 0 的章只显示字数；`已读不足 1%`、未知的 `—` 与未完成计数的 `+` 保持原样。当前章的章名与说明共同使用强调色。卷标题不显示覆盖，不增加整行底色或每章进度条。目录和详情中的覆盖均为累计估算值，不随统计期间切换，也不表示当前阅读位置。

### 计算与边界

章节覆盖的分母、并集、连续可见门槛、未知与清理语义见[统计规则](statistics.md#章节覆盖计算)。这里只定义展示：累计估算不随期间切换，不等于当前位置；未知为 —，未完整计数保留 +，不足1%单独说明。

## 数据、加载与职责

文件名、路径和下载状态归真实来源；补充信息归完整正文 SHA，同正文多来源共用。SwiftData 保存小说信息；Rust 查询对象内的 TEMP `book_metadata` 仅为计算输入，阅读片段使用 `visit_id`，当前版本见[数据与来源](../data/README.md)，后续格式演进保持旧数据可读并测试迁移。

### 编辑前的正文身份

| 文件状态 | 编辑动作 |
| --- | --- |
| 当前来源可验证，完整 SHA 已确定 | 读取该 SHA 的信息后编辑 |
| 原文未下载 | 提示下载，确认后下载/准备或取消 |
| 本机文件尚未取得完整 SHA | 使用既有准备流程，反馈状态，完成后才打开编辑表单 |
| 下载/准备失败或取消 | 留在详情，不产生待归并元信息 |

复用既有来源指纹验证、解码、规范化和 SHA 计算，不用原文件字节哈希代替正文 SHA。普通详情不自动下载；为编辑准备不计阅读。现有渐进阅读的进度、笔记、统计临时身份规则不变，小说补充信息不采用临时身份。

### 查询与采集

Swift 采集可见原文范围、正文交互和生命周期，Rust 负责计时、连续可见范围、并集和章节归属。图片处理不在主线程执行；书架批量取得封面引用，不逐行查询整本详情。

## 验证与剩余边界

关键回归包括 SHA 门槛、字段/标签并发合并、封面草稿/保存/移除/内容校验、跨检查点覆盖与清理重算，以及编辑保存、作者/标签筛选、阅读返回和章节列表。实际结果统一记录在[验证记录](../engineering/verification.md)。

真实附件上传/下载、账户切换和双设备合并仍需有资格的云签名环境；本地合并及图片校验不能代替云验收。回看分布和统计云端验收继续按[统计计划](../plans/statistics.md)推进。

## AI 资料审阅与书名

资料结果按一本书打开最终效果预览，标签 chip 与文本切换控制用户将要应用的更改。书名就是真实文件名，AI 可建议去掉明显噪声或响应明确改名要求；审阅展示完整旧文件名 → 新文件名，确认后仅对指定来源真实改名、保留扩展名、不覆盖同名文件。重命名和作者、简介、标签等资料独立保存并分别反馈。规则见 [工具契约](../ai/tools.md)。

## 1.3：V1 A

窄屏保持纵向摘要/操作/统计；页面可用宽度达到 760pt 时使用两栏，左侧保留书籍上下文或统计范围，右侧显示图表、时段与文件信息。当天统计同样分为摘要和时段两栏。身份未定和统计失败分别就近提示，不把全页变空；删除阅读数据与续读分开。数值定义复用[统计](statistics.md)，不改变返回阅读与计时。排期见[1.3 计划](../plans/1.3.md)。
