# 设置页与产品入口

更新：2026-10-24。本文描述当前设置入口；主题模型见[主题设计](themes.md)，样式来源见[现状盘点](ui-inventory.md)。多来源管理与 iCloud 设置入口已接入，真实云端验证边界见[接入实施](../data/sync.md)。

“阅读设置”以文字分类平级展示排版、配色、阅读控制，保留三档实时正文预览。书内先显示字号、配色和阅读方式快捷项，“更多”进入完整页面；设置页直接进入同一页面，见[阅读弹层](reader-panels.md)。单书独立设置暂缓，阅读统计规则见[统计专题](statistics.md)。

1.3 新增入口与后续分组规则见[设置信息架构](settings-information-architecture.md)；其中未实现内容不替代本页的当前行为。

## 顶层结构

顶层使用原生 `TabView`：AI 可用时为**书架、对话、统计、设置**，不可用时为**书架、统计、设置**，搜索始终是尾侧独立入口。设置 Tab 使用 `gearshape`，始终存在；书架、统计、对话首页不再有设置齿轮。AI 可用性只增减对话 Tab，当前对话消失时回书架，搜索返回来源同步校正。各 Tab 保留自己的导航位置。设置 Tab 根部直接使用 `NavigationSplitView`，不嵌在其他 Tab 的 push 栈里；书内“更多”保留当前阅读会话的偏好、编码和实时预览。统计菜单“统计设置”、书架管理、对话页“AI 助手”调节入口及备份 URL 统一定位设置 Tab 的对应任务，备份仍沿用导入确认。普通页面保留 Tab，正文和独立编辑呈现仍按各自边界处理。

仅正文阅读、带实时正文预览的阅读设置、完整对话页，以及文件多选任务显式隐藏 Tab。多选时底部由文件操作工具栏承接，完成后恢复正常浏览。其余页面保留系统自动规则，搜索激活和键盘交互交给原生搜索界面；sheet 自然覆盖底层界面，不另外修改 Tab。不要在根页或整个导航栈强制 `.visible`，也不通过出现/消失回调手动切换全局状态。侧滑取消仍保留当前页面和阅读预览。平台接口见 [toolbarVisibility](https://developer.apple.com/documentation/swiftui/view/toolbarvisibility(_:for:))。

自定义配色共用原生草稿编辑 sheet，阅读配色草稿同步到正文预览。单书搜索继续留在阅读器。

书架维持找书/继续阅读的职责；设置负责持续偏好与应用信息。选择小说目录仍在书架可直接完成，不强迫首次使用先去设置。原生 Tab 的系统形态按 iOS 版本呈现，不在 18 上仿制新版玻璃效果。[Apple Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)

正文维持沉浸式全屏，阅读页推到实际来源页面之上，正文不常驻底部 Tab；返回只退出当前阅读页，保留来源页面及选中的 Tab。上下滚动支持原生内容返回，分页支持系统起始边缘返回。

## 当前设置内容

设置首页沿用 release/1.3 的完整原生分节表单：阅读、书架与数据、AI 助手、外观与语言、帮助与关于。每行保留既有图标、摘要、条件显示和主题角色；分节标题不是额外导航层。紧凑宽度点条目直接进入对应页面，返回回首页，不增加选组步骤或任务切换栏。读取失败沿用原有提示，保存仍走既有串行入口。

| 分组 | 内容 | 进入后的行为 |
| --- | --- | --- |
| 阅读 | 阅读设置（上下滚动／左右分页） | 平级展示排版、配色、阅读控制及三档正文预览；方向项称“屏幕方向”，与阅读方式区分 |
| 阅读 | 阅读统计设置（记录中／已暂停） | “在此设备记录阅读统计”开关、计时说明及底部独立红色“清除阅读统计”（确认按钮同名）；统计 Tab 右上菜单“统计设置”（齿轮）进入同页，统计查看仍在统计 Tab |
| 书架与数据 | 书架管理（数量） | 与首页共用模型；固定我的书架、添加外部文件夹、重新连接及移除外部入口，文件操作仍作用于真实文件；顶部索引组提供自动建立索引开关 |
| 书架与数据 | 数据管理（备份、恢复、清理） | 总览提供备份、需要处理提示、阅读数据与缓存子页 |
| 书架与数据 | iCloud（阅读数据已开启／已关闭，异常时显示阅读数据同步异常） | 仅云构建显示；分别展示“阅读数据同步”与“我的书架文件”，关闭阅读数据不关闭小说文件同步；异常状态及文件冲突显示在对应组 |
| AI 助手 | AI 助手（连接数量；没有连接时为“未添加”） | 先“默认使用”：对话（模型与思考，原有弹出选择器）、联网搜索与图片生成（进入服务与模型页，行尾显示所选服务）；再“连接”列表与“添加连接”；右上问号进入使用帮助。顺序固定，不随配置状态变化；对话 Tab 左上调节按钮（AI 助手）进入同一页面 |
| 外观与语言 | 应用外观（跟随系统／浅色／深色） | 首行明暗模式（不另加同名分组标题）、“浅色时／深色时”两个配色槽、减弱动态效果及预览；阅读纸面配色留在阅读设置 |
| 外观与语言 | 语言（当前语言 · 系统设置） | 打开系统 App 设置，无障碍提示同样说明跳转；不维护应用内语言覆盖 |
| 帮助与关于 | 关于月读（版本） | 月亮、版本、准确的本机和可选 iCloud 数据说明及开源组件链接；“第三方许可”打开随包完整声明，支持滚动、选字、动态字号及深色，页首提供 MPL 组件具体版本源码链接 |

主题配色选择与当前明暗分开：明暗模式决定现在用哪一槽，“浅色时／深色时”只选择要编辑的槽，选择页标题为“浅色时的配色／深色时的配色”。编辑浅色槽时显示浅色预览，即使 App 此刻为深色。预设选择即时保存；自定义编辑有取消与确认操作，从当前所选预设或该明暗第一套配色复制全部颜色，新建后在列表中选择使用。长按或左滑自定义项可编辑/删除；删除弹窗说明使用中的槽位如何恢复默认。

阅读设置与其他设置详情一致，使用系统导航栏、返回按钮与侧滑返回；设置页底部预览最小仅为窄栏，上拉显示半屏/大档正文。纯浏览弹层用右上 `xmark` 关闭（章节/书签/笔记）；编辑弹层统一使用文字按钮：配色编辑与批注为左上“取消”、右上“完成”，小说信息为“取消／保存”。取消丢弃本次未提交的编辑，已有正式内容与未解决冲突保留。关闭/取消使用主题正文色，确认沿用强调色，删除使用破坏性操作色。搜索保留向下箭头收起与 `xmark` 关闭的区别；警告弹窗保留文字按钮，避免混淆确认和取消。

阅读页底部先提供字号、配色和阅读方式快捷项，通过“更多”进入同一个完整阅读设置页。全局设置只作入口复用，不复制一套表单、默认值和持久化逻辑。

## 新入口出现的条件

缓存管理、AI 凭据、朗读等仅在对应能力可用时加入，不以灰色按钮预占页面。未实现项与单书设置的暂缓决定统一见[后续计划](../roadmap.md)。当前“独立阅读主题”是阅读器级偏好，不代表每本书一份设置。

来源管理由首页与设置复用同一入口；我的书架的本地与 iCloud 位置均由应用固定管理，未启用云端也能正常导入，不提供位置选择或整库迁移设置，用户添加的根可移除。CloudKit 阅读数据开关默认关闭，开启后合并，关闭保留本机且不改变文件位置或系统同步，见[固定目录与同步控制](../data/sync.md#固定目录与同步控制)。授权失效原位重新连接，主动移除外部根后通过添加入口恢复。

搜索限额、数据库版本等实现细节不做用户设置。开发重置工具不出现在正式设置首页。

## 设置页面也要表现完整

- 行尾摘要正确反映继承和当前结果，默认项有选中态；关闭/重新进入/重启仍保留选择。
- 配色编辑失败保留草稿，不显示保存成功；取消预览不改正式偏好。
- 来源不可访问保留书架记录，给出重新授权路径；不要因进入设置扫描目录而冻结整个 Tab。
- VoiceOver 标签、较长英文、较大字号和系统降低透明度下，选项仍可操作；Tab 使用语义名称，不只放图形。
- 设置页颜色跟随 App 作用域，阅读内打开的主题/排版面板跟随 Reader 作用域；从阅读返回设置时无颜色串用。
- Tab 切换、返回、设置保存与开书转场遵循[统一动效](motion-and-moon.md)，不为每个设置行加跳跃动画。
- 字号、行距和主题偏好先即时更新界面，后台串行保存；连续操作合并待写值，不因短暂保存禁用或淡化整组控件。较早的保存结果不覆盖较新的主题选择，失败显示错误并回到最近成功保存的主题。
- 阅读方式选择器只接收模式值；改变字号、行距不重新配置其文字与选中态。模式切换保留原生反馈，正文仍即时重排并保留阅读位置。

## 支持月读

设置最后一组在“关于月读”下提供 `heart` 图标的“支持月读”，无行尾摘要；不在阅读器、书架或引导中放入口。三个 StoreKit 2 消耗型打赏均不解锁功能，名称、说明和当地价格来自 StoreKit。页面随应用主题使用 canvas、surface、ink、secondary 与 accent。

付款中各档暂停操作；取消静默恢复，失败行内提示并可重试；等待批准保留状态。应用启动监听已验证的交易与未完成交易，完成后 finish 并短暂显示感谢和月相渐盈；减弱动态时直接显示完成月相。金额、次数与打赏历史不写入应用存储，不提供恢复购买。App Store Connect 商品与协议、真机沙盒验证由开发者完成。

使用指南的章节与三条 TipKit 提示共用主题角色：卡片 surface、文字 ink、关闭及图标 secondary、与页面卡片一致的 border。书架跟随应用配色，阅读器内提示跟随阅读配色。

数据管理总览提供「导入备份 / 导出全部」按钮，生成后直接打开系统分享；需要处理的记录可进入按书归组的诊断页（无法归属的放其他记录）。阅读数据清单独立提供搜索、排序、全部/不在书架上筛选，后者按本机当前索引判断；改变搜索或筛选清空选择。选择态底部全选当前结果、删除所选，选择态右上角仅显示「完成」，删除全部放在底部选择栏菜单。缓存另页展示空间与清理，导入预览底部固定确认，错误与结果就近显示。小说详情的整书清除位于最后。

设置首页按阅读、书架与数据、AI 助手、外观与语言、帮助与关于分组，导航行显示当前状态。自动建立索引开关位于书架管理顶部的索引组。统计设置开关在上、清除在下：关闭只停止本机新增统计并保留历史，清除历史不改变开关。

## 阅读后的系统评分请求

仅正常退出阅读、最终位置与统计保存完成、回到书架并稳定后，才通过 SwiftUI `requestReview` 尝试请求系统评分。要求同时满足：按现有统计口径有至少三个不同自然日的有效阅读、本次有效时长至少五分钟、当前营销版本从未请求、距离上次请求至少 120×24 小时。工具页、后台与闲置扣除规则继续由同一个 ReadingClock 决定；不会另用开书到退出的墙钟时长。未返回书架、进入后台、正在打开书／处理文件、出错或有弹窗时跳过本次机会，不在后续前台恢复时补弹。

本机 UserDefaults 独立键 `Moonread.readingReview.requests.v1` 保存已请求版本集合及最后请求时间，不进入 CloudKit。调用前先记请求，系统未显示也不反复请求；应用无法得知是否实际显示或评分。读取不了记录时保留原值并跳过。系统是否显示由 StoreKit 决定，TestFlight 不显示属于系统行为。参见 [Apple 的评分请求说明](https://developer.apple.com/documentation/storekit/requesting-app-store-reviews)。不显示自定义预弹窗。

设置的“关于”区域始终提供“给月读评分”链接，打开 `https://apps.apple.com/app/id6823849812?action=write-review`，不受自动请求条件限制。

## 1.3 设置导航与任务呈现

采用方案 B：设置 Tab 根为两列系统 `NavigationSplitView`。sidebar 是同一份完整分节条目，保留 AI Toggle、语言外跳、评分及支持操作；regular 下以原生列表显示任务选中，compact 下保持 release/1.3 的原生分组表单观感与摘要。没有分组选择页、组内任务切换栏或第三导航列；外部动作不作为详情 selection。

详情列直接显示选中任务，内部钻取走固定 `NavigationStack`。`LibraryModel` 持有唯一 `SettingsNavigation`：当前任务 identity、深层路径、配色引用草稿和预览状态。宽屏初入可选择阅读设置，首次手机进入仍停首页；阅读偏好的当前值和串行保存由 App 级 `ReaderSettingsStore` 唯一持有，书内与设置页共享，不复制快照。已有任务、深层页面和草稿优先保留。折线、宽窄及内外屏适配由系统处理，不读保留区、不按机型重建宿主。

统计设置、书架管理、AI 助手和备份 URL 就近入口切到设置 Tab 的对应任务，不伪造返回来源按钮；未保存草稿不被外部入口替换。设置首页在 AI 可用与不可用时都使用 Tab 根大标题；release 中 AI 可用时的齿轮 push 小标题属于入口变化。手机各具体页面与 release/1.3 一致，阅读设置仍隐藏 Tab，保持原底部预览、档位与标题。regular 下保留系统 Tab 栏，预览放不下并排时在 detail 底部展开，不以 sheet 遮盖侧栏；侧栏选中项使用系统层级前景。正文内“更多”继续使用当前 ReaderSession；分栏不改变设置内容和保存语义。

AI 设置按 V2-R A 的原生分组呈现：默认用途三行使用共享模型选择组件，对话先显示模型/强度浮层，工具直接显示列表，连接每项一行，未登录就地提供登录入口，添加连接在末行、说明在 footer；共享列表始终可搜索、点选模型即保存并返回，强度由共享浮层的滑杆即时保存；连接与目录状态取自 AIConnectionService，不由持有凭据推断连接成功。iCloud 分为阅读数据与我的书架文件两个独立任务区，确认与重试贴各自状态，账户和替换确认流程不变。阅读设置内部与统计/详情整体布局仍沿现状，本轮不实现 V1/V4。
