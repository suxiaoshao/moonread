# 阅读弹层与工具布局

阅读正文与位置语义见[正文](../reader/reading.md)和[阅读工具](../reader/tools.md)，状态归属见[架构](../engineering/architecture.md#规则归属表)。以下为 1.3 的状态驱动实现；设备与连续操作的验证范围须单独记录，编译/单测不代表真机验收。

## 一个阅读 UI 会话

稳定的 ReaderScreen identity 持有 `ReaderUIState`。前台是阅读、某项工具或一个编辑任务；编辑任务持有稳定 ID、唯一草稿/重建作业引用、来源父链和返回上下文。搜索是否存在及展开意图在 `ReaderToolsModel.searchSession`，查询/结果/分段/列表位置不复制到呈现层。

`ReaderPresentationPlan` 从任务、布局能力和阅读事实纯推导根位、设置/详情路径及正文交互资格。同一输入得到相同目标树；宽度变化只更新布局事实，不 pop 业务任务、不生成待移交动作。

原生宿主在既有来源 NavigationStack 外挂载：根位互斥为 inspector、一个稳定 flow 的 sheet、锚定进度 popover 或无呈现。原生安装状态只保留当前节点/内容引用和转场事实；退出完成后读最新 plan，不排队执行旧目标。程序性释放不当作用户取消；旧 token 不结束新任务。离开本书仍由既有保存/退出逻辑执行。

## 全尺寸系统工具栏

手机、regular 与系统竖栏共用目录、搜索、阅读设置、进度、更多五个命令。点正文显隐系统导航和工具栏，不绘制第二套四列 dock、快捷设置或更多网格。顶部书签直接添加/移除当前位置，保存成功才更新实心状态；封面与保存中禁用。更多只列小说详情、跳转历史及文字编码，不重复书签/批注列表。

水平进度入口显示当前展示位置百分比，竖向栏显示 percent 图标并提供百分比可访问值。全书未准备完成时只显示“进度”；不显示虚假总页数，也不因打开进度提交正式续读位置。SDK 的 `toolbarVerticalEdge` 仅在 iOS 27.1 起读取，较早系统沿用水平系统命令和原生 Menu，不提高部署下限。

## 按当前布局承载任务

- compact：目录/搜索在唯一根 sheet；完整阅读设置与小说详情使用来源栈真正的原生 push，保留系统返回/侧滑。进度按需打开 sheet；系统竖栏可用时锚定原生 popover 并由系统适配。
- regular：能容纳工具列且正文未解析为双页时，目录/搜索/设置共用 inspector；否则使用唯一根 sheet，设置包含原有内联预览。可用性依据空间、现有正文叶数和原生排版的最小列宽，不检测机型。自动退让不修改手动展开偏好。
- 活动编辑：创建时固定父链。正文/inspector 编辑留在阅读根 flow；目录内编辑保留目录 NavigationStack；设置页/预览发起的配色编辑始终保留相应父页。宽窄只改变系统适配，编辑 ID、输入、错误和作业引用不变；完成后才按当前布局返回。
- 设置的预览→配色编辑→系统 ColorPicker 沿用既有嵌套链。尚未释放的原生子节点保留父页，关闭回执只释放原生引用，不推进下一个业务任务。
- 搜索收起后保留相同查询、结果和列表位置；regular 可继续在侧栏显示结果，不能由 appear 把展开意图改回 true。选中结果显式收起搜索意图，折回 compact 仍是精简附件。
- 临时浏览的返回/继续与删除撤销在发生时自动可见：有 inspector 放其底部，否则使用精简根附件，不要求先打开进度。不恢复常驻进度卡。

## 阅读设置：三个同级分类与上拉预览

```text
        ‹ 返回                  阅读设置
                [ 排版 | 配色 | 阅读控制 ]
        字体、字号、行距
        段落、边距与行宽；设置区域独立滚动

                         ━
        阅读预览                               ⌃
        当前书名
        正文预览从这里向上展开，大档按实际阅读宽度显示
```

- 设置是标准导航页面，预览使用同一个 SwiftUI 原生 `sheet`，通过 `.height(60)`、`.medium`、`.large` 提供三档高度。最小档仅显示拖动条和“阅读预览”窄栏，不显示正文；上拉后才显示半屏/大档正文。最大档仍是原有 sheet，不切换页面。拖动、吸附、圆角和档位过渡由系统处理。点击窄栏展开到半屏，再点展开到大档；大档点击收回窄栏。
- 半屏按系统容器尺寸排版；大档使用实际阅读宽度，并复用正文的字号、边距与最大行宽。容器变化允许重新换行，保留预览原句。使用原生 `.presentationSizing(.page)` 和默认尺寸适配，不强行把内容撑到容器外；`presentationContentInteraction(.resizes)` 负责扩展与内容滚动衔接。[Apple presentationSizing](https://developer.apple.com/documentation/swiftui/view/presentationsizing(_:))
- 竖屏小、中档通过 `presentationBackgroundInteraction` 允许操作上方设置，列表末项可滚到预览上方；大档遵循系统模态行为。设置列表和预览不因档位变化被移除重建。横屏遵循系统整页呈现，点收起返回设置，通过底部“阅读预览”按钮再次打开，不自制横屏抽屉。
- 预览纸面保持所选阅读配色；键盘避让交给系统，输入焦点由所在编辑面板持有。
- 排版直接包含字体、字号、行距、首行缩进、段间距、左右边距、最大行宽，不藏进二级页。五项数值均为点（pt），标签直接显示单位，例如“字号 · 23 pt”“最大行宽 · 680 pt”；行距是行与行之间额外增加的距离。设置页 与阅读入口复用同一个编辑器和全局偏好。
- 配色包含明暗跟随规则、“浅色时／深色时”槽位和预设/自定义；选择编辑深色槽只改变预览，不修改当前阅读明暗模式。两套颜色共享同一份排版参数。
- 从正文进入时捕获当前有限窗口、原文位置和标记；从设置进入用原创示例正文，展示标注与搜索的不同颜色。预览使用与正文相同的 `ReadingTypography` 和 `ReadingLayoutManager`，无独立排版规则。
- 预览没有阅读会话，不保存进度、不触发新章加载、不控制亮度与常亮。调整排版或旋转时保留预览原句；背后的实际正文停止交互，设置变化仍保持原阅读锚点。
- 自定义配色复用应用主题的原生 `PaletteEditor`。从预览的呈现层打开草稿编辑 sheet，草稿颜色同步到后方正文；系统 `ColorPicker` 从当前编辑面板打开，避免从被 sheet 覆盖的页面请求模态呈现。横屏设置页未打开预览时，直接呈现同一编辑器。取消不修改正式颜色，应用配色保留应用组件预览。
- 设置即时保存，使用系统导航栏的返回组件和侧滑返回。自定义配色草稿等独立任务保留明确的取消/确认语义。参数名称保持稳定，不让每次数字变化重建模式选择器；使用原生 Stepper、Slider、Picker 与 Toggle。
- “阅读控制”与排版、配色平级，直接提供阅读方式、常亮、方向和亮度；切换分类保留预览档位。设置页 只保留“阅读设置”入口。
- 正文与设置页 两个入口均在现有导航栈中进入主题页。导航开始时同步收起预览，不等 `onDisappear`，设置列表继续保留原避让高度，避免页面在返回途中伸缩。取消侧滑后，等页面回弹与 sheet 关闭均结束再恢复原档位和预览位置；确认返回后保持关闭。切换分类不触发导航或重新呈现预览。被设置覆盖不结束阅读会话。

## 同一个资料面板

目录入口统一为“章节 / 书签 / 批注”，唯一选择值是 `ReaderToolsModel.tab`。sheet 与 inspector 共用同一 header、分段、列表和编辑 owner；书名只显示一次，次要行显示已有的当前章节与可用百分比，不触发全书分页。

章节识别、卷层级、字数/覆盖及整理动作沿用原实现；重建只启动一次，仅在明确结束任务时取消，不在 view disappear 时结束。书签/批注保留现有摘录、笔记、单条编辑/滑删与撤销；无书签说明顶部添加方式，无批注说明选字方式，并提供返回阅读。记录行增强、多选、分享和批量删除属于后续范围。

## 交互与验证边界

所有保存结果按编辑 ID 生效：失败保留同一任务和错误；成功/取消立即完成逻辑任务，不用 completedEditor 占位，取消后可立即重进。退出动画的内容引用属于原生安装层，不参与编辑准入。

轻点、选字、翻页、临时浏览与正式续读/统计仍走原 owner。进度与历史不隐式确认新的续读位置；布局变化不更改规范正文、持久化键或同步格式。UI 使用阅读主题的 surface/ink/secondary/accent/separator/destructive 和原生栏，不自画系统材质控件。

单测保护纯投影、草稿/查询保留、取消重进、旧结果隔离与原生释放准入。ColorPicker 系统关闭行为不写 UI 驱动；实际 iPad 缩窗、Duo 适配、手机连续操作交由对应的真机试用，不能以纯函数或 Debug 编译代替。
