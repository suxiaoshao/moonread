# AI 模型目录与能力卡片

目录服务、能力卡片及缓存已接入。这里维护模型字段与获取规则；Pi/Zed 的固定版本调查及证据边界见[历史依据](../research/ai-integration-history.md)。

## 页面与数据契约

保留模型详情的身份区、能力分组卡片、思考滑杆、容量卡片及使用按钮。能力分组为三列两行，图标在文字上方，固定顺序如下。支持的使用主题色，其余置灰，卡片不增加第三种状态；资料不足时在相关说明中解释。

| 位置 | 卡片 | 公开补全字段（A/S 明确字段优先） |
| --- | --- | --- |
| 第一行左 | 文字对话 | `modalities.input` 与 `output` 均包含 `text` |
| 第一行中 | 图片输入 | `modalities.input` 包含 `image` |
| 第一行右 | 深度思考 | `reasoning == true` |
| 第二行左 | 图片生成 | `modalities.output` 包含 `image` |
| 第二行中 | 工具调用 | `tool_call == true` |
| 第二行右 | 结构化输出 | `structured_output == true` |

字段未明确支持时不启用。`structured_output` 是可选字段；缺省也置灰，不把缺省写成已证实的供应商限制。音频、视频、温度、流式回复不放入能力概览。联网搜索与图片编辑由相应服务适配器判断，不能从工具调用或图片输入输出推导，不在这六张卡片中混入。

思考开关不等于具体档位：档位来自连接目录或适配器的明确配置，不能从 `reasoning` 推导六档。多档显示离散滑杆，单档仅显示，无思考能力隐藏调节区。容量显示当前连接上下文与最大输出，缺少数值不编造，也不把 SDK 的安全默认值作为规格。不设“模型资料”展开区。模型 ID 与展示名不同时，放在名称下方并提供复制；相同时省略。连接模型区以一句话说明来源与核实边界；检查时间保留在内部数据中。连接限制直接反映在相关能力和容量上。有经过核实的官方模型链接时，在页面底部提供轻量文字入口；无链接则省略，不生成猜测 URL。

## 目录来源、刷新与预算

`AIModelDirectoryPolicy` 按预设的 provider、认证、发送协议与精确端点选择目录契约；修改地址的自定义连接按用户选择的协议解析，不冒充官方账户目录。目录集合与能力规格分别处理：

- A：使用本连接凭据读取的完整官方目录。OpenAI API、OpenRouter（登录和 API key）、Anthropic、Gemini、xAI、DeepSeek、Mistral、Moonshot 两区、Kimi Code 两区、Alibaba 国际、MiniMax 国际、小米、Meta、Baseten、Groq、Cerebras、Together、Fireworks，共 21 个入口。只有 OpenRouter 的 `/models/user?output_modalities=text,image` 明确应用账户筛选；其他列表不等于余额或逐型号调用授权。
- S：Vercel、DeepInfra、Hugging Face、OpenCode Zen/Go 的官方公共动态目录，共 5 个入口；不发送用户 key，不因刷新成功清除凭证错误或宣称 key 已验证。
- P：models.dev 的精确 provider ID / model ID 公开规格，保留内置快照和条件请求缓存。其余 15 个预设继续 P/M，不盲试 `/models`，不跨套餐或区域借用目录。
- M：用户显式填写的型号与预算。普通 API 保留通用文字请求尝试；不凭手填自动开放原生联网搜索、图片或工具。OpenRouter 成功目录未列出的手填记录仍保留，但不可用来绕过过滤。ChatGPT 不添加手填型号。

A/S 完整成功后（含空集合）决定自动发现集合；P 只补稀疏字段，不把名单外型号加回。显式 `false` 覆盖公开资料；缺省字段才补全，思考布尔值不制造档位。未补齐能力的新型号保留信息入口，但不自动成为对话或工具默认。OpenAI 的普通列表不带完整能力；Responses 端点兼容与托管工具用途仍由 `AINativeCapabilities` 单源判断，不把列表中的音频或专用型号当作普通对话型号。禁用模型仍不改变已有会话的执行配置。

`AIModelDirectoryDecoder` 处理代表性的 OpenAI 稀疏对象、Anthropic/MiniMax 身份与分页、Gemini 方法与分页、Together 数组、百炼 output 分页、Fireworks 服务过滤与分页、公共网关对象。完整分页验证后一次替换；重复 ID 有冲突、坏结构、循环游标或非 200 都算失败，不保存部分结果。凭证只进契约规定的请求头，目录请求不跟随重定向，不使用响应里的跨站 next URL。基本列表没有写明的能力不按型号名称推测。Baseten 未核实的目录限制与 HF 未固定路由的容量不当作连接硬上限。

字段在 `AIModelCatalog.option/resolve` 中唯一合并：合法正数 A/S 容量优先于 P；显式控制优先于 P，思考 false 清掉档位。手填预算原样保存，执行取 `min(预算, 明确连接上限)`；最大输出再受有效上下文和明确输出上限约束。Google/Anthropic 的输入上限仍按输入预算使用，不自行加成总上下文。

同连接并发刷新等待同一任务；P 共享下载，S 按精确目录端点共享 24 小时缓存。普通入口只检查过期目录，手动刷新可越过年龄；失败记录本次尝试时间，不循环重试。失败保留同连接上次成功集合；A/S 从未成功时列表为空并提供重试；普通 API 仍可手填。P 仅补已有列表型号的规格，不给 A/S 提供候选集合；15 个 metadata-only 预设继续使用 P 列表。空集合不是失败。403 保留凭证与显式模型配置，401 提示检查本连接凭证，公共刷新不能解除该错误。换 key、退出或配置身份变化使旧请求失效，迟到结果不得回写新连接。

兼容基线为已发布 1.4：旧普通 API 的 `models` 可能来自公开资料。A/S 连接没有同身份的成功来源标记时，不恢复其中的自动发现项，只保留显式手填项，等待目录刷新；不把旧 `modelsChecked` 当作成功目录证据。15 个 metadata-only 连接与既有 ChatGPT 账户快照保持原样。不迁移 1.5 开发中间结构。配置、手填预算、默认 ID、启停集合与已有对话保留；目录变化不自动换模型。

ChatGPT 账户目录保持独立 SIWC：slug、visibility=list、服务器顺序、24 小时缓存、套餐授权及预算规则不变；目录后来提供容量时替换手填预算并提示，不借 P 或普通 API 目录补型号。

## 验证范围

覆盖离线启动、缓存命中不重复下载、手动刷新、失败保留旧数据、账户隔离、六项字段映射及连接限制覆盖。页面以同一份示例数据验证三列两行、置灰与思考档位，不用真实供应商名称承载虚构规格。

资料：[models.dev](https://models.dev)、[最终模型 schema](https://github.com/anomalyco/models.dev/blob/dev/packages/core/src/schema.ts)。内置快照为当天 models.dev 数据的所需字段投影，位于 `ios/Moonread/AI/Providers/AIModelCatalog.json`；完整类型、解析与刷新在同目录 `AIModelCatalog.swift`。公开资料获取不包含凭证；A 目录只使用相应连接的已有凭据。公开目录不证明当前账户有权限；实际调用失败照常展示服务错误。官方模型链接无可靠数据源时省略。测试证据见[验证历史](../engineering/verification-history.md)。

多协议预设在目录中额外保留模型名称和 `provider.npm`，后者仅用于 OpenCode 网关的单模型路由。区域及套餐使用各自目录键；不借用相近区域的数据。


### 请求适配

目录保留原始控制类型、values、min/max；是否可展示/发送由同一适配器确定，不把 reasoning 布尔值变成虚构档位。各协议 wire 参数与历史回放见[请求适配](providers.md#思考参数适配)。

### 模型选择呈现

快速模型控制保留原生 popover，由系统在手机适配为 sheet，宽屏使用 popover；内容可滚动，不锁定实际宽度。快速页使用一个稳定 NavigationStack，显式 medium/large 档位；模型与思考强度用原生分组，模型行只显示模型身份，强度标签独立显示当前档位。完整列表作为同宿主的导航子页，系统返回保留快速页与当前强度，根页关闭结束流程；按用途直接进入完整选择的入口不变。模型保存成功才关闭整个流程、失败留在列表；AI 不可用时宿主退出整个流程。关闭快速控制不撤销已生效的思考强度。
