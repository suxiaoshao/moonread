| 列表及详情 | 列表分页100项/50 KiB，完整单项不因统一64 KiB拒绝丢弃；搜索书籍逐个返回真实文件。简介、批注摘录详情及来源不再有8000字符、5/50个来源等额外硬截取。列表短摘录显式标记。 |
| 游标 | 查询签名与偏移编码，不保存会话内游标表、不设10分钟过期或数据修订失效规则。查询变更/无效偏移仍属参数错误；数据变动后按当前查询结果继续。 |

| 原生搜索/图片 | 删除查询/提示长度、通用引用数量、响应/附件字节及像素等应用附加限额，不截掉答案或来源。服务协议确实要求的参数、支持格式、引用归属继续由适配器校验。xAI参考图不硬编码旧的三张规则；[官方多图编辑文档](https://docs.x.ai/developers/model-capabilities/images/multi-image-editing)已更新，实际服务校验当前模型要求。 |

## 已确认的月读产品行为

这些属于已确认的功能，不冒充 Pi 的实现：

- 网络/API失败不自动重试，用户发送“继续”；Pi 的默认自动重试未照搬，遵守此前明确决定。输入超窗的一次压缩重试保留。
- 准备小说前提示用户，工具不能修改正式阅读位置或写阅读统计；书架及引用身份仍使用最终业务服务。
- 对话存储按50条分页、UI快照节流、模型目录缓存和认证轮询属于 iOS 存储/展示/服务接口，不限制 Agent 的工具执行或历史总数。
- 共享正文准备租约避免同时损坏同一导入任务；这不是工具结果去重。JSON类型、枚举、有效范围、UTF-8边界和模型实际容量校验保留。
- Markdown、SwiftData、URLSession 和 Swift AI SDK 继续使用现有架构，不另写一套 Pi 的 TypeScript 执行器。

验证结果见 [verification.md](verification.md)。本地协议模拟测试不能证明真实供应商登录、收费请求或图片服务已实际运行。
