## 阅读扩展候选

以下能力尚未实现，是否做及先后顺序仍按实际需要选择。参考依据见[阅读器源码对照](research/readers.md)。

| 能力 | 当前边界与建议做法 |
| --- | --- |
| 更多目录识别规则 | 当前有常见标题、卷/章两级、人工纠错与重建。通用正则编辑器、规则选择和任意层数目录尚无；先收集识别失败样本，再决定规则入口 |
| 正文搜索范围与语法扩展 | 当前为单书字面量/单行 Rust 正则、分批有界输出且不静默截断总结果。书架文件名搜索已有全局/局部范围；跨行正则和全库正文搜索尚无，不能宣称支持完整 ripgrep 功能 |
| 笔记整理扩展 | 列表按原文顺序，已有 Markdown/纯文本导出及章节标题；列表按章分组、独立整章记录与整本读后感仍未实现，选中章节标题写批注已经可用 |
| 朗读 | Swift 接系统语音和音频生命周期，Rust 提供有界文本与位置；方案已定、当前基线尚未合入；听书与阅读共用正式阅读位置 |
| 繁简显示转换 | 不改原文件；Rust 必须提供可靠的显示文字到原文范围映射，保证搜索、选字和批注仍定位原文；规则库与许可证待选 |
| 仿真翻页 | 当前为原生左右分页，未做纸张卷曲效果。若增加，只作为可选转场，保留现有分页边界、有界页面和减弱动态方案 |
| 配色导入/导出 | 当前可在本机新建、编辑、删除配色，尚无配色文件交换；需要先确定交换格式和校验规则 |
| EPUB/PDF | 当前只支持 TXT。新增格式单独确定结构、资源和位置模型；PDF 固定版面不能套用 TXT 重排 |

## 明确暂缓与后续产品阶段

- **单书独立设置：暂缓。** 当前排版与阅读控制是全局偏好，不先引入每本书一套覆盖与继承；单书暂停统计同样保持候选。
- **目标、打卡、速度估算、外部统计导入/导出：候选。** 不抢占书籍、阅读时间与时长的主位置；预计读完时间明确不做。
- **删书后笔记管理与专用“添加原文”入口：暂缓。** 不与阅读时间线捆绑；既定的笔记保留、同正文重新关联继续有效。
- **其他同步通道：后续候选。** iCloud 已接入代码但真实云端仍待验收；自定义目录、WebDAV 是否接入及先后未定，不提前实现多后端。
- **Android：尚未实现。** 复用 Rust 业务核心，原生 UI 与平台组件到对应阶段确定。

公开段评、点赞和社区账号不属于个人阅读器方向，不作为缺失功能补入。
