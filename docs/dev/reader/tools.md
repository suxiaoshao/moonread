# 阅读工具：章节、书签、搜索与私人批注

状态：已接入章节目录、书签、单书搜索、范围标注与私人批注。工具复用渐进 TXT 的规范 UTF-8 位置，支持滚动与分页；工具栏已移除“上一页 / 下一页”按钮，保留翻页手势。结果统一见[验证记录](../engineering/verification.md)。

已确认：评论属于自己的私人批注，围绕个人阅读记录设计。目录、搜索和批注与正文共用阅读主题作用域；继承、独立配色和系统明暗规则见[主题设计](../design/themes.md)。

目标是让读者在正文中随时找得到、记得下、回得去。功能使用共同的定位与内容版本契约，默认沉浸阅读不增加常驻按钮。

## 操作入口

| 场景 | 入口与行为 |
| --- | --- |
| 连续阅读 | 保留顶部章节/时间/电量细栏；正文不出现成排工具或评论气泡 |
| 展开工具 | 底部“目录、搜索、设置、更多”为四个等宽操作，图标在上、名称在下，使用主题 ink；四项均一步直达；“设置”和“更多”与快捷设置相同，在同一底部面板中替换工具上方内容，两者互斥，选中时使用强调色。进度滑条与前后章直接显示；有上下文内容时隐藏 |
| 随手留位置 | “更多”面板的第一项“书签”名称固定：未添加时为空心图标，添加后原地以原生符号替换动画变为实心，图标与名称使用强调色，不加底色，正文右侧同时出现记号；面板保持打开以便看到结果，不定时收起、不新增触感。封面上和保存进行中不可用；失败时状态不变并显示错误。辅助功能读作“书签”，带已添加/未添加状态与“添加或移除当前位置的书签”提示，语音控制也接受“添加书签”“移除书签” |
| 找回记录 | 底部“目录”打开目录，“更多”面板中的“书签列表”“笔记”打开书签与标注与笔记列表；三者为独立目的地，没有分段切换，记录按正文顺序浏览 |
| 记录一句话 | 长按后直接标注、拷贝或全文搜索；系统箭头展开同一菜单，可查询/翻译和写批注 |
| 跳到其他地方 | 目录、搜索结果、书签和标注均可跳转；返回正文时短暂强调目标，提供“回到刚才” |

目录、书签列表、标注与笔记是三个独立目的地，各自以大尺寸 sheet 打开，标题分别为“目录”“书签”“标注与笔记”，右上 ×，不再有常驻分段切换。底部“目录”直接打开目录，“搜索”和“设置”（快捷设置）同样一步直达。第四列“更多”与快捷设置一样是底部面板的一种内容：常规字号下为四项，与底部四列工具使用同一标签样式（图标在上、名称在下、同样字号、列宽与 56pt 可点高度，不加图标底板），依次为“书签”（开关）、“书签列表”、“笔记”、“详情”，书签列表使用列表图标以区别于书签开关；辅助功能字号下改为同样短名称的纵向行。“笔记”“详情”的辅助功能名称为“标注与笔记”“小说详情”，语音控制两种名称都接受。书签开关、两个列表和详情各需两步。打开列表前先同步选定目标列表，第一帧即为目标标题；切换到另一种记录时立即清空上一种的行并显示加载，旧请求以代次作废，不出现目录或另一种记录的行；同种记录刷新时保留现有行。从“更多”打开的列表沿用目录的展开路径，在同一 sheet 中由“更多”的高度连续展开为大尺寸；点 × 或下拉回小档时回到“更多”，选择记录并跳转正文时回到阅读。从底部“目录”直接打开的目录关闭后仍回到阅读。小说详情有两个入口：阅读页导航栏右上的原生信息按钮（主题 ink），工具显示时一步打开；以及“更多”中的“详情”。两者有意并存，从详情返回都恢复打开前的面板（包括“更多”）；封面页自身的“小说详情”保留。三者便于查找后下滑返回正文；不采用半高面板容纳长列表。搜索与进度、章节临时浏览、快捷设置共用一个原生底部面板；搜索药丸可在同一呈现中展开为详情。面板通过一个活动状态管理，同一时间只展开一个，不叠加多个 sheet。第一次展开目录定位当前章节，搜索保留本次查询与结果。关闭面板后，正文视口和当前行不发生无意移动。

底部所有快捷内容共用 ReaderBottomPanel，内容优先级为快捷设置、搜索、临时浏览、默认进度；每次只展示一个主要内容区，撤销反馈另占紧凑一行。展开工具栏时面板按内容测量高度并通过原生 detent 连续变化，正文视口不变；临时浏览保留同一组按钮，搜索展开详情时收起工具栏。快捷设置仅替换内容，关闭后恢复原有查询或浏览原点。

目录、历史和批注与快捷区共用同一个原生 sheet，切换时改变内容和高度；打开任务会收起四列入口。任务关闭后直接回到沉浸阅读，只恢复仍需要的搜索、临时浏览或撤销药丸；例外是从“更多”打开且未选择记录的书签或笔记列表，关闭后回到“更多”，“更多”中显示仍可用的撤销行。这一来源只保存在当前阅读页内存中，跳转、批注编辑、进入详情或设置页、离开阅读时清除。完整阅读设置继续使用页面导航，进入时无动画释放 sheet，不串联两段完整转场。查询、选项、命中和列表位置不丢失；暂时隐藏不停止后台搜索，主动关闭搜索或退出阅读时取消任务。撤销药丸的六秒可操作时间在面板遮挡或应用不活跃时暂停，上移/下移不重置时间。

退出阅读走统一清理流程：确认退出时固定待保存的原阅读位置，隐藏临时浏览、撤销与跨页选取提示，停止搜索和界面查询；后到的回调不得再次显示浮层。按钮返回会先关闭已有 sheet，等待系统关闭完成回调和进度写入后，通过当前阅读页的 `dismiss` 恢复实际来源；不使用固定延迟拼接动画，也不清空导航栈。系统交互返回在确认完成时复用保存和清理流程，不再次执行 pop；取消手势保留原会话。视图消失清理可重复调用，同一次退出复用保存任务与位置；保存失败交给入口的错误提示展示。

只显示已能完成操作的入口；暂未实现的工具不以不可点击按钮占据阅读界面。界面文案、无障碍标签接入[本地化](../design/localization.md)约定；配色遵循已接入的[主题规则](../design/themes.md)，并检查系统浅深外观。

## 章节列表：知道读到哪里，也能回到原处

每章字数下已显示累计估算覆盖，当前章标题、字数与百分比共同强调，保留完整目录快照。连续可见 3 秒才参与覆盖，快速掠过与跳章不补齐；未知记录显示 —。布局、清理重算与字符口径见[小说详情](../design/book-details.md#章节列表里的阅读百分比)。

自动识别“第 N 卷”和“第 N 集”为上级分组，其后的章/回/节归入该分组；进入下一组后章号可以重新开始。规则同时用于首次正文准备和目录重新识别，不改原文。

- 无筛选时首项为“封面”，独立于章节编号与字数，不参与目录纠错。封面可从滚动和分页模式回看，沿用临时浏览及原位置保护；在封面时不同时选中第一章。
- Rust 一次返回已解析章节的完整轻量快照，打开时定位当前章，前后所有已解析章节均已在内存中；SwiftUI 仅按需创建可见行。当前章标题与右侧字数都使用主题强调色；字数为正文非空白 Unicode 字符数（含标点，英文按字符），排除章标题，不用 UTF-8 字节数估算。未完成导入的最后一章以“已准备字数+”表示。
- 正文准备时同步记录块边界、章节起点及标题结束处的累计非空白字符数，章字数由相邻有效章节的计数差取得。打开目录只读计数与标题，不读取正文或重新计数。人工增删、恢复、重新识别及同步章节修正均遵循同一边界；修改显示名不会改变原文标题的扣除量。列表使用稳定原文偏移 ID，没有前后分页游标、边缘加载哨兵或前插补偿逻辑。
- 目录 sheet 栏内：左侧“…”只放目录整理工具（整理目录／重新识别目录／恢复自动目录），右侧 ×；不在目录里重复小说详情。栏内图标使用主题 ink。推入的目录编辑和重新识别页面保留各自标题与操作。
- 查找框使用阅读主题的 input、ink、border/focus，提供搜索图标与清除，占整行，不再常驻定位按钮。搜索行下留 8pt 后直接进入目录。聚焦空框不改变视口；输入直接过滤完整快照，结果从顶部展示，跨越折叠卷且不改变章字数。清除查询恢复当前章并展开所属卷。改变筛选和关闭面板不改变正文进度。封面行与章节行使用同样的行高、内边距与分隔线。
- “回到当前章”是浮在列表底部的胶囊，只在当前章是目录中的有效项、且因滚动不可见、被筛选隐藏或所在卷已折叠时出现；键盘弹起时不出现，阅读封面或没有当前章时也不出现。它占用列表底部安全区，最后一行可滚到它上方。点按只滚动目录，不移动正文；有冲突筛选时先清除并展开所属卷。可见性只在当前页面内判断，不保存。
- 选择章节后收起面板，跳到对应标题的原文位置；章节标题不能藏在顶部信息栏后面。跳章不改写原文，不把存储分块当成章节。
- 导入尚未完成时列出全部已识别章节，并说明目录仍在准备；面板打开期间跟随已提交正文及完成状态刷新快照，也可手动刷新。后台更新保留筛选、折叠和当前视口，不主动跳回当前章。没有识别出标题时说明情况，仍能继续读全文。
- 章节索引随正文处理增量建立，打开目录不重建整书。识别短行中的“第 N 章/回/节/卷”、英文 `Chapter N` / `Volume N`，以及楔子、序章、序言、前言、终章、尾声、后记、番外、外传、引子和常见英文前后记；候选不超过 80 字。卷可折叠，打开目录/定位当前章会展开所属卷，筛选跨越折叠状态。
- 章节操作菜单可整理目录、重新识别或清除人工修正。选字菜单可将短独立行设为章节；目录项可修改显示名、卷章层级、排除误识别项并撤销排除。所有修改只写索引覆盖，不改 TXT。重新识别分批执行、可取消、先预览再原子应用，人工修正默认保留；导入完成前不提供纠错和重建。
- 目录跳转前记录阅读锚点，“回到刚才”回到跳转前的段落，不用当前页码反推位置。

### 正文定位规则

底部默认直接显示进度：滑条拖动预览章节，松手定位；也可输入 0–100 的百分比、跳到前后章或打开跳转历史。未完成导入时不显示全书百分比。历史最多 32 项，只记录显式跳转，回退/前进不重复入栈；新跳转截断前进分支。历史始终独立于最初续读原点，“回到刚才”恢复原点，“从这里继续读”才确认正式位置。

百分比按规范正文 UTF-8 位置比例计算，定位时校准字符边界，不表示精确字数比例或全书页码。历史仅属于当前阅读会话，结束临时浏览后清理。

- 滚动模式跳章节，将标题所在行放在阅读区顶部，保留正常上边距。
- 滚动模式中的搜索和笔记列表批注定位，把命中放在无遮挡正文区上方约三分之一，留出前文；可见区扣除底部搜索药丸或返回操作。完整命中已经清楚可见时，只改变高亮，不移动文字；跨长段范围优先保证起点可见。
- 分页模式打开目标所在页，保留已有分页边界和目标在页内的位置。同页切换搜索命中不重建页面；载入其他窗口时复用重叠区分页。
- 第一次临时跳转保存原视口：同一排版下，“回到刚才”恢复原文行及其屏幕纵向位置，分页恢复原页边界。期间改变字号、行距、模式、方向或动态字体后，按原文锚点重新定位。
- 视口记录只属于当前会话，最多保留一份原位置的有限窗口分页数据；持久化仍使用 Rust 的 UTF-8 原文位置。连续跳转不覆盖最初的返回点。

## 书签：记录一个位置

- 书签保存当前正在读的原文位置，附原文短摘录以便辨认，不要求先选择文字或填写名称。
- 同一位置再次点击快捷操作可移除；不同位置可以分别保存。列表支持回跳和删除，删除提供撤销。
- 工具栏添加与移除都等待实际写入成功后，以既有工具栏动画回到沉浸阅读；保存中忽略重复触发，失败保持正文位置与工具栏，给出错误提示。
- 书签与阅读进度独立。打开书签列表不改变进度，点选才发出明确跳转请求。
- 翻页、改字号、旋转或换主题后仍指向同一段文字，书签不使用页码、像素坐标或临时分块编号作为身份。
- 正文在书签对应行右侧的既有 16pt 页边距中显示主题强调色 `bookmark.fill`，图标占 12×20pt，随实际字形行滚动、分页与重排。同一显示行的多个书签合并为一个记号，原有记录分别保留。
- 记号作为无交互的叠加绘制，不占文字宽度、不改变行距或选字，也不额外接管边缘手势。书签仍通过工具栏和列表管理；批注继续使用文字底色。
- Rust 按当前阅读窗口的半开区间查询书签位置，Swift 只为可见行保留图标视图；分页隐藏的排版后文不显示记号。添加、移除、列表删除/撤销及重开后同步刷新，无需更改数据库格式。

## 搜索：先找到上下文，再决定跳转

首轮范围为单书搜索。默认普通文本，提供正则和大小写选项，正则采用 ripgrep 默认引擎的语法；不启动 `rg` 子进程，不在首轮加入 PCRE2、全库搜索或任意跨行模式。

- 搜索在 Rust 中执行，Swift 只接收分批、有数量上限的结果；用户修改查询或真正关闭搜索时取消旧任务，旧结果不能覆盖新查询。收成药丸时继续本次搜索，不重启任务或清空结果。原生复用列表保留位置，再展开时恢复。
- 搜索栏把查询、清除、正则 `.*` 和大小写 `Aa` 图形按钮放在同一行，选项启用时使用主题 accent/accentSurface 和选中态，并保留本地化无障碍名称。下方显示结果数量、进度或停止/刷新图标。错误在面板内显示，避免输入无效正则时连续弹警告框。
- 结果显示章节、命中前后文及命中强调；点选结果才跳到正文，并带动画收成底部药丸。药丸显示查询、当前序号、前后命中按钮及“回到刚才 / 从这里继续读”；收起时可以操作背后的正文。拖拽条上拉或点击查询展开搜索详情，下拉收起；查询、选项、结果及列表位置属于同一搜索会话。使用系统 sheet 高度转场和内容渐变动画，遵循减弱动态效果，不重建或缩短正文视口。
- 列表普通命中使用主题 search，当前选中命中和正文定位都使用 searchCurrent；摘要文字使用 ink，章节名/数量使用 secondary，选中行背景使用 selected。预设保持搜索冷色与永久标注暖色的区别，自定义读取各自独立颜色，不固定写死蓝色/黄色。修改查询或选项立即移除过期的正文搜索强调；永久标注、搜索强调和系统选区分别处理。
- 搜索启动时固定已提交正文前缀、正文身份与应用纠错后的有效目录；任务各批次使用同一版本，目录随后变化只影响新搜索。搜索读取规范化后的同一内容版本。缓存块边界不能漏掉跨块单词或汉字匹配；UTF-8 偏移与 UI 范围转换必须一致。
- 使用有界读取、短数据库事务及独立工作调度，不持有导入写锁或主线程。超长行、结果过多和正则编译错误要有明确反馈；不能为了搜索把整本复制进 Swift 或无界堆内存。
- 导入中以开始查询时的已提交前缀为搜索范围，显示“已准备内容中的结果”；全文未准备完时不能声称“全书无结果”。准备范围增加后允许刷新查询，不让后台增长不断重排当前结果列表。
- 无查询、无结果、查询错误、部分范围、已取消和结果达到上限分别表达。零长度正则命中不产生不可见结果或无限循环。

当前使用 Rust `regex`（与 ripgrep 默认语法同源），由核心按行流式扫描规范正文。单行上限 1 MiB，查询上限 4096 字节，编译与 DFA 缓存各限 2 MiB；每批最多返回 50 条，不设总命中截断；UI 累积结果的规模成本见[性能待优化](../engineering/performance.md#待优化)。每次读取只持有短事务，任务支持原子取消。结果摘录限制上下文与命中展示长度，原文定位范围仍完整。

## 标注与评论：记录一段文字及自己的想法

标注是原文范围上的圆角高亮；评论是关联该范围的文字记录，两者共享定位对象，避免重复保存两套不一致的原文位置。可以只标注而不写文字，也可以选中文字后直接写评论。

选中“第1章”等章节标题同样可以写批注，用来记录对这一章的感想。记录锚定标题文字范围，从笔记列表点击回到标题；当前列表按原文顺序展示，尚无章节分组。无需为这种使用方式新增独立的整章评论类型，也不把选中标题自动扩大成覆盖全章的高亮。整本读后感及不依附文字的独立章节记录留在后续。

### 范围与选择

- 原生选字菜单分为常用动作（标注、拷贝、全文搜索）、系统工具（查询/翻译及系统提供的其他动作），以及同一组中的批注与高级操作（写批注、整段批注、跨页选取、章节纠错，顺序不变，彼此之间不加分隔线）。分组用分隔线，继续使用系统横向菜单及其箭头展开列表，不嵌套自定义“更多”。拷贝使用普通菜单项并读取完整选区原文，复制内容排除封面显示附件；系统 lookup 分组整体保留；系统依次提供仅为内联的 `.learn`、（可有可无的）`.speech`、`.share` 分组时，合为一个无标题内联分组，沿用原对象与顺序（语音分组本身原样嵌入），其他结构原样保留，包括其标识和动态动作，不拆成子项快照，不依赖私有 selector。菜单可见宽度、溢出和系统命令可用性由 iOS 决定。全文搜索复用当前书内搜索，填入选中文字并按普通文本查找，不改变阅读位置。选区、菜单和编辑弹层的手势优先，不能同时翻页或退出阅读。[Apple 文字编辑菜单](https://developer.apple.com/documentation/uikit/uitextviewdelegate/textview(_:editmenufortextin:suggestedactions:))
- “搜索网页”由系统查询分组在展示阶段补充。不能仅看最初的 `suggestedActions` 子项判断最终可用动作，也不能拆掉 lookup 分组后自行重建同名按钮。保留原生分组后，iOS 27 实际展开菜单已恢复该项；不固定搜索引擎或调用私有 selector。
- 点按已有批注与手动选字共用原生文本上下文和一套选区判断、菜单生成逻辑。点按在原生 Select 命令执行期间指定批注范围，防止命令缩回单词，再通过公开的 `UITextSelectionDisplayInteraction` 隐藏选区显示；不显示选择杆，原生查询、翻译、搜索网页继续使用文本上下文。手动选字仍显示系统选择杆。点按选区为该批注完整范围，跨页时拷贝、全文搜索仍使用完整原文。
- 没有交叉时，主要操作为标注、拷贝、全文搜索；只要有文字交叉（包含、被包含、部分交叉、跨多条都相同），主要操作为编辑批注、移除批注、拷贝、全文搜索。移除使用系统危险色并排在编辑之后。不区分有评论/无评论；不要求完整覆盖；仅首尾相邻不算交叉。系统工具居后，写批注、批注整段、跨页选取、设为章节合为最后一个无标题的内联分组，不增加自定义“更多”。
- 编辑器按正文位置将涉及的非空评论以 `\n\n` 拼接到一个输入框。打开编辑不修改正式范围或评论，也不保存空高亮。文字、范围与冲突选择只属于本次会话；X 或下拉关闭直接丢弃，不恢复、不询问放弃确认。勾号才由 SwiftData 事务合并并保存为一条，空评论仍保留高亮。任一参与条目的并发冲突都必须先解决，保存再次核对整组候选。明确执行“标注”立即保存高亮，取消随后打开的评论编辑不会撤销已有高亮。
- 移除由 Rust 按选区查询完整相交集合，不依赖当前页加载了多少条记录；整条移除，不切割选区外的残片，多条一起撤销。拷贝、翻译、搜索仍针对当前选区，合并范围只用于批注编辑与保存。
- 存储块边界不能截断选区或保存少一段文字。滚动选字、分页选字、跨块与跨页范围是独立验收场景；不能以当前页高亮成功代替完整范围正确性。
- 原文保持只读；摘录、标注、评论和书签均属于应用用户数据。

### 正文底纹

- 标注使用按字号而非行高绘制的浅暖色圆角底纹；底纹贴近字身，不覆盖额外行距，跳过段落分隔符，避免整块染色段间空白，不增加页边按钮或预留标记栏，不改变正文宽度、行距和分页。轻点高亮直接展示标注菜单；选择“编辑批注”后才打开编辑器。命中检测排除空白边距与行间空白，标注点击优先于边缘翻页，长按继续使用系统选字。临时定位使用另一种颜色，与永久标注区分。
- 标注仅保留圆角底纹，不绘制下划线。使用 TextKit 原生绘制钩子添加底纹；排版和选字仍由原生组件处理。永久标注底纹先绘制，原生选区与临时搜索强调叠加其上。
- 正文仅绘制当前窗口内的标注。高亮范围与颜色独立保存在布局管理器的绘制状态中，增加、删除、改色与搜索强调只使显示失效，不写入正文 `NSTextStorage`，不重排或重设滚动位置。重叠标注合并绘制，避免半透明底色叠深；深浅色变化只重绘动态颜色。临时搜索命中与永久标注分开存储；选区、当前搜索命中和已有标注重叠时仍能辨认。

### 编辑器、键盘与关闭

- 详情显示摘录与输入区；进入时自动聚焦并弹出键盘。点击摘录或输入区外留白收键盘，点击输入框恢复编辑，滚动支持交互式收键盘。
- 一个原生滚动视图协调表单。输入区有浅底色、圆角和细边框，焦点以强调色边框表示；初始高度至少 104pt，随内容增长，可见边界与实际编辑区域一致。
- 原生点击手势处理框外收键盘，框内光标与选字交给系统。正文菜单交出第一响应者，输入区等待系统弹层转场完成回调再首次聚焦，不使用固定延迟猜测时机。键盘布局指南负责表单避让，不叠加 SwiftUI 避让。
- 左上叉号（无障碍名称“关闭”）直接丢弃本次未提交编辑，右上勾号（“完成”）正式保存。编辑器不提供删除按钮，移除统一在正文标注菜单和笔记列表中操作；顶部中央保留系统拖拽条。下拉关闭由系统协调键盘与弹层动画。
- 底层正文忽略弹层键盘避让，不重新分页。关闭完成后统一刷新标注，消失时不写入任何批注内容，也不重复调整焦点或刷新正文；保存失败在阅读页提示。

### 确认、取消与删除

- 编辑文字、范围和冲突选择仅留在内存。确认前离开编辑页不改变正式批注，未解决的正式冲突继续保留。新建编辑取消后不留下批注；再次打开从正式内容或空白开始。
- 移除批注由用户明确的删除操作执行，并提供撤销；取消编辑不会执行删除。
- 书签和笔记列表左滑为红底删除操作，显示文字与垃圾桶图标，删除后可撤销。

## 文案与提示

界面不常驻操作教程、自动保存说明或实现细节。批注编辑保留摘录、输入区和顶部操作；目录、搜索、书签和笔记空态只用简短状态表达。保留错误、准备进度、搜索范围未覆盖全书、跨页选取中等会影响当前操作判断的信息。

评论仅是用户自己的私人批注，不引入其他读者、公开段评、点赞、回复关系或社区账号。未来同步也在用户自己的设备之间进行。

## 共同的数据与定位契约

| 对象 | 核心信息 | 归属 |
| --- | --- | --- |
| 内容身份 | 稳定书籍 ID、规范化正文 SHA；SHA 用于已完成内容匹配 | Rust |
| 位置锚点 | 规范 UTF-8 字节偏移，必要的前后文作为校验与辨认信息 | Rust |
| 范围锚点 | `[startUtf8, endUtf8)`，原文摘录及有限上下文；边界必须有效 | Rust |
| 书签 | 稳定 ID、位置锚点、创建/修改时间 | SwiftData 持久化，Rust 校验位置 |
| 标注/评论 | UUID、范围锚点、摘录、完整候选与操作基线 | SwiftData 持久化；未提交编辑仅在会话内存 |
| 导航请求 | 目标锚点、来源、临时强调范围、请求代次 | Rust 目标校验，Swift 执行原生定位 |
| 返回记录 | 一个临时浏览原点；继续跳转仍保留该原点，尚无多步历史 | Swift 会话状态，位置采用共享锚点 |
| 搜索任务 | 查询代次、选项、内容版本、已准备范围、结果游标和完成状态 | Rust 执行，Swift 展示 |

公共身份、位置、持久化和开发格式规则统一见[架构与数据](../engineering/architecture.md)。跨平台模型不保存 UIKit `NSRange`、字体或颜色对象；未来同步协议不属于当前工具实现。

渐进导入期间可对已提交前缀建立记录，关联当前稳定任务身份；完成去重时由 Rust 解析正式书籍映射，保留用户分别写下的评论，不因相同摘录覆盖内容。编码重开或源文本变化产生不同内容版本，旧记录保留在原版本；上下文相似只能作为重定位候选，不能静默贴到新正文。

只打开面板、浏览结果或改变选区不覆盖续读位置。目录、搜索、书签和批注定位先进入临时浏览，当前位置与已保存的续读位置分别表达；浏览时可以滚动/翻页查看上下文，这些动作本身不等于确认继续阅读。

选择“从这里继续读”才把目标位置转为正式续读起点，此后按正常阅读规则保存。浏览期间保留进入浏览前的位置，支持“回到刚才”；退出阅读、进入后台或进程结束时，未确认的临时位置不覆盖原续读记录。跳转失败或用户取消交互返回时保持当前位置。浏览过程中明确新增或编辑的批注可正常保存，与是否更新续读位置分开处理。

## 已接入的使用场景

| 顺序 | 可完整使用的阅读场景 | 必须一起完成的基础 |
| --- | --- | --- |
| 1 | 目录找到章节 → 跳章 → 回到刚才；随手加书签 → 重开找回 | 共享导航请求与返回记录、完整目录快照、书签持久化、面板状态、本地化和现有浅深配色适配 |
| 2 | 输入查询 → 看到上下文 → 定位命中 → 返回结果或原位置 | 可取消有界搜索、跨块位置、部分范围提示、临时命中强调 |
| 3 | 选择句子 → 标注/写个人评论 → 重排后仍可查看和编辑 | 范围锚点、选择菜单、标注渲染、编辑取消与确认保存/撤销、跨块及跨页验收 |

尚未实现的扩展和明确暂缓项集中于[后续计划](../roadmap.md)，这里不另设阶段顺序。

## 以实际阅读验证

- 从正在读的段落跳到另一章、一个搜索命中或书签后，能准确回到原处；操作面板本身不移动正文。
- 临时浏览中滚动、翻页、切后台或退出后，原续读记录保留；选择“从这里继续读”后才开始保存新的阅读位置。
- 选中章节标题可添加私人批注，并从笔记列表回到该标题；批注不意外高亮整章，也不因章节分组重复保存。
- 一万章级目录一次读取轻量元数据并惰性呈现；大量书签/搜索结果仍采用有界查询，正文继续使用有限窗口，打开面板不冻结阅读。
- 导入中打开目录、搜索和添加记录；暂停、恢复及完成去重后，记录与位置仍一致，部分内容不会被伪装成完整结果。
- 标注跨缓存块，改字号/旋转/切换模式后范围不变；评论仍对应原句；搜索高亮退出后不破坏永久标注。
- 浅色/深色、简中/英文、较大字号和 VoiceOver 下检查正文与工具，不仅验证数据库行或按钮是否存在。

## 当前实现边界

- SQLite 版本见[当前存储](../data/README.md#当前实际存储)；全局排版/控制设置使用完整类型，自动章节与人工覆盖分开保存。发布后数据通过版本迁移保持旧记录可读，原 TXT 文件不修改。
- 目录为完整元数据快照，笔记每批 60 条。仅当前正文窗口查询并绘制批注。正文范围和整段批注最多 1 MiB，单条批注正文最多 64 KiB。
- 跨页批注通过原生菜单“从这里跨页选取”确定起点，翻页后选中终点并点“批注到这里”；“批注整段”由核心读取完整段落，不被当前页面截断。此操作不改变系统复制的选区语义。
- 主题选择器已接入阅读设置；真实云端验收、整本感想、全库搜索或全文跨行正则尚未实现，公开评论不属于个人阅读工具方向。

## 验证入口

已有绘制、目录/搜索、批注键盘与删除撤销等回归及其真机限制集中于[验证记录](../engineering/verification.md)，日常构建与试用见[开发环境](../engineering/development.md)。以上“以实际阅读验证”列出场景标准，不表示每项均已在所有设备验收。

目录重新识别预览的可应用状态由真实重建任务是否完成、未取消且有效以及当前工作状态决定；加载更多／应用的瞬时错误仅提供反馈，保留同一“应用目录”入口供用户再次操作。任务未就绪、取消或原正文已失效时仍不可应用，不自动重试。离开预览继续取消对应重建任务。
