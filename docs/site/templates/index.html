{% if zh %}你可能还想知道{% else %}A few things to know{% endif %}

{% if zh %}支持哪些文件？{% else %}Which files can I read?{% endif %}

{% if zh %}目前支持 TXT，会自动识别常见编码和章节。月读不提供书城、书源或小说下载。{% else %}TXT files, with automatic detection of common encodings and chapters. Moonread has no bookstore, content sources, or book downloads.{% endif %}

{% if zh %}换手机，进度还在吗？{% else %}Will my place move to a new phone?{% endif %}

{% if zh %}“我的书架”的文件通过 iCloud Drive 同步；开启阅读数据同步后，进度、书签和批注通过 CloudKit 私有库同步。外部书架在新设备上需重新授权；字体、排版与当前配色选择保存在本机。{% else %}Files in My Library sync through iCloud Drive. Reading-data sync uses your private CloudKit database for positions, bookmarks, and notes. Authorize external folders again on a new device. Fonts, typography, and the selected palette stay on this device.{% endif %}

{% if zh %}备份里有小说吗？{% else %}Does a backup include my books?{% endif %}

{% if zh %}没有。全部阅读数据备份与单本笔记导出是两件事；TXT 小说文件需要另行保存。{% else %}No. A backup of all reading data is separate from exporting a book’s notes. Keep your TXT files separately.{% endif %}

{% if zh %}AI 是必需的吗？{% else %}Do I have to use AI?{% endif %}

{% if zh %}不是。支持该功能的店面中，AI 默认关闭，使用你选择的服务与账户；不用 AI 也能完整阅读。部分地区不提供 AI 功能，包括中国大陆店面。{% else %}No. Where available, AI is off by default and uses a service and account you choose. Reading works fully without it. AI features are unavailable in some regions, including the mainland China storefront.{% endif %}

{% if zh %}月读开源吗？{% else %}Is Moonread open source?{% endif %}

{% if zh %}是的。代码托管在 GitHub，采用 MIT 许可证。欢迎查看代码，也欢迎提出 issue，反馈问题或建议。{% else %}Yes. The code is on GitHub under the MIT License. You are welcome to explore it and open an issue with a bug report or suggestion.{% endif %}
