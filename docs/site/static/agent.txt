Use Moonread exports, never novel text, to identify books. Keep content_sha256 and reference unchanged. Do not infer matches from titles or paths. Missing fields mean unchanged; null does not clear. Explicit clear/rename requests require user review in the app. This is metadata editing, not a reading-data backup.
