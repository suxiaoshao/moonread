# Metadata examples

`metadata.json` and `metadata.jsonl` show the transport shape with synthetic placeholder identities (repeated 1/2). They are not valid identities for your books. You may create a manifest directly from TXT or edit a Moonread export; neither shape requires a prior export.

For a runnable direct-generation example, use [sample.txt](../identity/sample.txt) and [generated.json](../identity/generated.json), plus the [identity reference](../identity/README.md). Calculate hashes for your actual TXT; preserve valid existing hashes when editing. Add/index the corresponding TXT in Moonread before importing metadata.
